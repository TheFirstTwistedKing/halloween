# 🎃 할로윈 봇

이벤트 채널에서 채팅하면 **🍬 할로윈 재화**(이름·이모지·최대량은 관리자가 바꿀 수 있어요)를 모으고, 가끔 나타나는 **📦 패키지**를 뜯고, **상점**에서 물품과 역할을 사고파는 디스코드 봇이에요.

## 규칙 한눈에
| 항목 | 내용 |
|---|---|
| 재화 | 기본은 **할로윈 재화** 🍬, 최대 **99,999개**. `/재화설정`으로 이모지·이름·최대량을 바꿔요 |
| 채팅 보상 | 채팅 한 번에 **50%** 확률로 🍬 **1~5**개 |
| 패키지 | 채팅 한 번에 **0.1%** 확률로 그 채널에 나타남. 뜯을지 말지는 각자 선택 |
| 패키지 결과 | 기본은 **꽝 60%** · 🗝️ 열쇠 20% · 🍬 50개 10% · 🗑️ 쓰레기 10%. `/패키지결과`로 종류·확률·보상·아이콘을 바꿔요 |
| 상점 | 관리자가 물품·역할을 등록. 물품마다 **구입 true/false**, **판매 true/false** |
| 가방 | `/가방`: 내 재화·물품·가진 역할 |
| 채널 지정 | 재화·패키지는 **관리자가 정한 이벤트 채널에서만** |

## 명령어
**누구나**

|---|---|
| `/가방` | 내 재화·물품 확인 (본인에게만 보임) |
| `/도움말` | 이 서버의 확률·채널이 반영된 안내 |
| `/던전` | 입장 물품(기본 🗝️ 열쇠 1개)을 내고 던전에 들어가요. 진행 중이면 내지 않고 이어서 해요 (본인에게만 보임) |

**관리자 전용** (서버 관리자 또는 서버 주인. 일반 멤버에게는 메뉴에도 안 보여요)

| `/던전보상 목록·추가·수정·삭제` | 던전 클리어 때 받는 추가 보상 물품(개수·확률). 재화 범위·획득권 확률은 `/던전설정` |
| `/패키지결과 목록·추가·수정·삭제` | 패키지를 뜯었을 때 나오는 결과(꽝·재화·물품), 확률, 보상 개수, 아이콘·이름 |
| `/몬스터 추가·수정·삭제` `/장비 추가·수정·삭제` `/소모품 추가·수정·삭제` | 던전의 몬스터·보스·장비·회복 아이템을 새로 만들고, 고치고, 지워요(이름·이모지·수치 전부) |
| `/던전목록` `/던전콘텐츠초기화` | 던전에 지금 있는 것 전체 보기 / 기본 목록으로 되돌리기 |
| `/던전설정` `/던전설정확인` `/던전설정초기화` `/던전시뮬` | 던전의 공통 수치(체력·방어·보상·방 배치)를 바꾸고, 보고, 되돌리고, 클리어율을 시험해 봐요 → 아래 **던전 밸런스 조정** |

## 던전
패키지에서 얻은 🗝️ 열쇠 1개(기본값, `/던전입장물품`으로 바꿀 수 있어요)로 `/던전`에 들어가요. 방이 **10번** 나오고 턴제로 싸워요. HP는 1,000이에요.

**방 배치** (고정된 순서예요)
| 방 | 내용 |
|---|---|
| 1·3·5·7·9번째 | 🎁 보물 상자 (장비 1개 + 소모품 1개) |
| 2·4·6·8번째 | 🚪 빈 방 40% · ⚠️ 잡몹 60% |
| 10번째 | 👑 미니 보스 (이기면 클리어) |

**전투**
- **공격**: 잡몹은 회피 10%(명중 90%), **거대 쥐는 회피 30%**, **보스는 회피 불가(항상 명중)**. 석궁·총처럼 '회피 확률 변환' 무기는 잡몹에게만 적용돼요(보스에게는 영향 없음).
- **방어**: 가드 성공 확률 60%. 성공하면 ① 이번 피해를 줄이고(기본 60%, 방패는 더 많이) ② 그 공격 피해의 **50%만큼 HP 회복** ③ 그 공격 피해의 **30%를 몬스터에게 반사**(나무 방패 40%, 방패 50%) ④ **몬스터가 다음 공격을 못 해요**(💫 기절). 실패하면 그대로 맞아요. 회복량이 받은 공격에 비례해서 방어만 반복해도 HP가 불어나지 않아요.
- **아이템 사용**: 전투 중엔 한 턴을 써요. 기절한 몬스터는 그 턴도 공격하지 못해요.
- **상자**: 장비는 **장착/버리기**를 정해야 앞으로 갈 수 있어요. 장비·소모품은 그 던전 안에서만 써요.

**장비** (일반 등급 상향) — 낡은 몽둥이 +30 · 단검 +35(크리티컬 50%) · 나무 방패(가드 80%, 반사 40%) / 희귀·전설은 그대로예요.

**몬스터** (원래 수치의 약 90%로 너프)
| | HP | 공격 | 회피 |
|---|---|---|---|
| 🦇 거대 박쥐 | 225 | 65 | 10% |
| 🟢 슬라임 | 270 | 45 | 10% |
| 🧙 마녀 | 135 | 135 | 10% |
| 🐀 거대 쥐 | 90 | 45 | 30% |
| 💀 해골 왕 | 900 | 135 | 0% |
| 🟩 거대 슬라임 | 1,125 | 90 | 0% |
| 👺 고블린 왕 | 810 | 180 | 0% |

**끝**: 10번째 방(보스)을 이기고 앞으로 가면 클리어(기본: 🍬 50~150 + 10% 확률로 🎟️ 히든 칭호 획득권, 그리고 `/던전보상`으로 정한 추가 물품). 쓰러지거나 나가면 보상 없이 끝나고 입장에 쓴 물품은 돌아오지 않아요.
**이어하기**: 봇이 꺼지거나 화면을 닫아도 진행은 저장돼요. `/던전`을 다시 치면 입장 물품 없이 이어서 해요. 클리어 보상은 한 번만 나가요.
획득권은 `/가방`에 표시돼요. (칭호 교환 기능은 아직 없어요.) 위 수치는 **기본값**이에요. 서버 관리자가 디스코드에서 `/던전설정`으로 바로 바꿀 수 있어요(아래 참고). 코드에서 기본값 자체를 바꾸려면 `balance.py` 맨 위를 고쳐요.

## 던전 밸런스 조정 (관리자)
코드를 열지 않고 디스코드에서 던전 수치를 바꿀 수 있어요. 바꾼 값은 **서버마다 따로** 저장되고, 봇을 껐다 켜도 유지돼요. 진행 중인 던전에도 바로 적용돼요(이미 나타난 몬스터의 체력·공격은 그대로).

| 명령어 | 설명 |
|---|---|
| `/던전설정 항목 값` | 값을 바꿔요. **항목**은 글자를 입력하면 자동완성이 나와요(예: `방어`, `방3`, `보상`). 자동완성에는 지금 값과 기본값이 같이 보여요 |
| `/던전설정확인 [분류]` | 비우면 **바꾼 항목만**, 분류(일반·방 배치)를 고르면 그 분류의 전체 값을 보여줘요. ✏️ = 기본값에서 바꾼 것 |
| `/던전설정초기화 [항목]` | 항목을 고르면 그것만, 비우면 전부 기본값으로 되돌려요(전부일 땐 확인 버튼이 나와요) |
| `/던전시뮬 [판수]` | 지금 밸런스로 컴퓨터가 던전을 대신 돌려 **클리어율**을 보여줘요(방식마다 100~3,000판, 보통 1초 안팎) |

**`/던전설정`으로 바꿀 수 있는 항목** — 이름은 `분류.속성` 모양이에요.
- **일반**: `일반.최대체력` · `일반.맨손공격력` · `방어.성공확률` · `방어.기본피해감소` · `방어.회복률` · `방어.기본반사` · `보상.최소` · `보상.최대` · `보상.획득권확률`
- **방 배치**: `방1.상자` `방1.빈방` `방1.잡몹` `방1.보스` … `방10.보스` — 10개 방마다 네 가지가 나올 **가중치**예요(합이 100일 필요 없이 비율로 써요. 0이면 안 나오고, 한 방의 네 값이 모두 0이면 거절돼요).
- 몬스터·보스·장비·소모품의 수치는 `/몬스터` `/장비` `/소모품` 명령으로 바꿔요(아래).

**안전장치**: 범위를 벗어난 값, 정수여야 하는 곳의 소수, 보상 최소>최대, 한 방/장비/아이템의 가중치가 전부 0인 설정, 나올 몬스터·보스가 하나도 없게 되는 설정은 거절하고 이유를 알려줘요. 거절된 값은 저장되지 않아요. 방어를 반복해서 HP가 줄지 않거나 늘어나는 조합(예: `방어.회복률`을 크게 올림)은 **저장은 되지만 ⚠️ 경고**를 보여줘요. 값을 기본값과 같게 바꾸면 바꾼 기록이 사라져요.

**바꿀 수 없는 것**: 방 개수(10개 고정), 보스는 회피 불가라는 규칙, 전투·방어의 진행 방식(가드 성공 시 회복·반사·기절 같은 규칙 자체. 수치는 바꿀 수 있어요).

**시뮬레이션 읽는 법**: 컴퓨터가 장비를 기대 공격력이 높은 쪽으로 고르고 회복 아이템을 알뜰히 쓰면서 세 가지 방식(공격만 / 체력 60% 아래에서만 방어 / 기절 아닐 땐 항상 방어)으로 플레이한 **어림값**이에요. 실제 유저는 보통 이보다 낮게 나와요. 쓰러지는 방 분포도 같이 나와서, 어디가 벽인지 볼 수 있어요.

## 재화·물품·패키지·던전 편집 (관리자)
모두 **서버마다 따로** 저장되고, 봇을 껐다 켜도 유지돼요. 이모지는 일반 이모지 하나 또는 그 서버의 이모지(`<:이름:ID>`)를 쓸 수 있어요.

**재화** — `/재화설정 [이모지] [이름] [최대]`: 비우면 현재 값을 보여줘요. 이름·이모지는 채팅 반응, 가방, 상점, 안내문, 패키지 결과 등 **모든 화면에 바로 반영**돼요. 최대 보유량을 **낮추면** 그보다 많이 가진 사람이 줄어들기 때문에 몇 명이 줄어드는지 보여주고 확인 버튼을 눌러야 적용돼요(올리는 건 바로).

**물품** — 기본으로 만들어지는 🗝️ 열쇠·🗑️ 쓰레기도 다른 물품과 똑같이 `/물품수정`으로 이름·이모지·설명을 바꾸고 `/물품삭제`로 지울 수 있어요(처음 한 번만 만들고, 지워도 다시 만들지 않아요). 다만 **던전 입장 물품이나 패키지 결과표가 쓰고 있는 물품은 지울 수 없어요**(먼저 `/던전입장물품`·`/패키지결과`에서 바꿔 주세요). `/던전입장물품 물품:입장권 개수:2`처럼 입장에 내는 물품과 개수를 바꾸고, 물품을 비우면 무료 입장이에요. 역할은 입장 물품으로 쓸 수 없어요.

**던전 클리어 보상** — 재화 범위(`보상.최소`·`보상.최대`)와 획득권 확률(`보상.획득권확률`)은 `/던전설정`으로, 추가 물품은 `/던전보상 목록·추가·수정·삭제`(물품·개수·확률 %)로 바꿔요. 물품 보상은 항목마다 **따로 확률을 굴려요**(100이면 항상, 0이면 안 나옴). 클리어했을 때만 나가고 최대 10개예요. 보상으로 쓰는 물품은 지울 수 없어요(먼저 `/던전보상 삭제`).

**패키지 결과** — `/패키지결과 목록`으로 지금 표를 보고, `추가`(종류: 꽝/재화/물품, 확률, 물품, 개수, 이모지, 이름)·`수정`·`삭제`로 바꿔요. **확률은 비율**이라 합이 100이 아니어도 돼요(목록에는 계산된 %가 나와요). 결과가 하나도 없거나 확률이 전부 0이 되는 변경은 거절돼요. 이모지·이름을 비워 두면 물품·재화의 것을 그대로 써요(수정에서 `-`를 적으면 다시 자동으로). 최대 20칸.

**던전 콘텐츠** — `/던전목록`으로 지금 있는 것을 보고 아래 명령으로 바꿔요. 처음 손대는 분류는 지금 목록을 통째로 복사해 와서 그 위에 더하고 빼요(그 분류의 예전 `/던전설정` 숫자는 같이 반영돼요).
- `/몬스터 추가 이름 이모지 체력 공격 [회피] [보스]` · `수정` · `삭제` — 보스는 마지막 방에, 잡몹은 짝수 방에 나와요. 보스는 항상 회피 불가예요.
- `/장비 추가 이름 이모지 종류(무기/방패) 등급 등장 …` · `수정` · `삭제` — 무기는 공격력·크리티컬·회피변환, 방패는 가드(필수)·반사. 수정에서 `-1`은 '해제'예요.
- `/소모품 추가 이름 이모지 등급 등장 …` · `수정` · `삭제` — 효과는 한 가지: 회복량 / 전체회복 / 지속회복(+지속턴). 수정에서 새 효과를 정하면 이전 효과는 사라져요.
- `/던전콘텐츠초기화 [분류]` — 직접 만든 것·바꾼 것을 기본 목록으로 되돌려요(확인 버튼).
- 이름은 같은 분류 안에서 겹칠 수 없어요(몬스터와 보스는 서로의 이름도 쓸 수 없어요). 분류당 몬스터·보스 25개, 장비·소모품 50개까지.
- **진행 중인 던전은 깨지지 않아요**: 지운 장비를 쓰고 있던 사람은 맨손처럼 싸우고, 아직 정하지 않은 상자 장비가 지워졌다면 [장착]/[버리기]를 눌러 안내만 받고 앞으로 갈 수 있고, 지운 소모품은 소지품에서 안 보여요. 이미 나온 몬스터는 그대로 싸워요.

## 역할 재화 지급 (관리자)
`/역할재화지급 역할:@손님 수량:30`처럼 쓰면 그 역할을 가진 **모든 사람**에게 🍬를 줘요(수량이 음수면 회수).
- **확인 단계**: 명령을 치면 대상 인원과 총량을 먼저 보여주고, **[지급] 버튼을 눌러야** 실제로 나가요(취소하면 아무것도 안 바뀌어요). 미리보기에 나온 명단 그대로 처리돼요.
- **대상**: 그 역할을 가진 사람 중 **봇은 제외**해요. `@everyone`을 고르면 서버의 모든 사람이에요.
- **한도**: 사람마다 0~99,999개 안으로 맞춰요. 상한 때문에 덜 받거나 0 아래로 못 내려간 사람이 몇 명인지 결과에 알려줘요. 전부 한 번에 저장돼서 수천 명도 빠르고, 중간에 실패하면 아무에게도 반영되지 않아요.
- **기록**: 누가·어느 역할에·몇 명에게·얼마를 줬는지 봇 콘솔 로그에 남아요.

**켜는 방법 (처음 한 번)** — 이 기능은 역할을 가진 사람 전체를 알아야 해서 *서버 멤버 인텐트*가 필요해요. 안 켜면 다른 기능은 그대로 되고, 이 명령만 켜는 방법을 안내하고 멈춰요.
1. 개발자 포털 → 봇 → **Bot** 탭 → **Server Members Intent**를 켜요.
2. `.env`에 `MEMBERS_INTENT=true`를 적어요.
3. 봇을 다시 시작해요.

포털에서 인텐트를 안 켜고 `.env`만 `true`로 하면 봇이 시작되지 않고 그 이유를 알려줘요(`.env`의 값을 지우면 돌아와요). 인텐트를 켜도 시작할 때 모든 멤버를 미리 불러오지는 않아요.

## 처음 설정 순서 (관리자)
1. `/이벤트채널추가 채널:#할로윈` — 재화와 패키지가 나올 채널을 정해요.
2. `/물품등록 이름:호박 초 구입:true 판매:true 구입가:30 판매가:10 이모지:🕯️` — 물품을 등록해요.
3. `/역할등록 역할:@유령 손님 구입:true 판매:false 구입가:200` — 사면 역할을 받는 물품이에요.
4. `/상점등록 채널:#상점` — 그 채널에 상점이 떠요. 물품을 바꾸면 상점 메시지가 **자동으로 새 목록**으로 바뀌어요.
5. (선택) 🗝️ 열쇠와 🗑️ 쓰레기는 처음엔 가방에만 쌓여요. 사고팔게 하려면 `/물품수정 물품:쓰레기 판매:true 판매가:2`.
6. (선택) 재화 이름·이모지는 `/재화설정`, 던전 입장 물품은 `/던전입장물품`, 패키지에서 나오는 것은 `/패키지결과`, 던전의 몬스터·장비는 `/몬스터` `/장비` `/소모품`.

## 자세한 규칙
**재화와 쿨타임.** 같은 사람이 **3초 안에 연달아 보낸 메시지는 한 번으로** 셉니다(매크로·도배로 재화를 긁는 것을 막으려는 안전장치예요). 확률·쿨타임은 `/이벤트설정`으로 바꾸고, `재화쿨타임:0`이면 모든 메시지를 세요. 패키지 확률도 같은 방식으로 센 메시지에만 적용돼요. 재화를 얻으면 메시지에 재화 이모지(기본 🍬) 반응이 붙어요(바쁜 채널에서는 요청 제한을 피하려고 채널마다 1초에 한 번만).

**최대 보유량.** 재화는 기본 99,999개가 최대예요(`/재화설정`으로 변경). 채팅·패키지 보상은 상한까지만 들어가고, 판매는 **상한을 넘기게 되면 거절**해요(물건을 잃지 않게). 물품 가격도 이 최대값까지만 정할 수 있어요.

**패키지.** 나타난 채널에서 **120초** 동안 머물러요(`/이벤트설정`으로 변경). 한 채널에는 한 번에 하나만 나와요. 두 가지 방식이 있어요.
- **누구나 한 번씩**(기본): 패키지를 낸 사람이 아니어도 모두 뜯을 수 있고, **각자 자기 결과**를 받아요(본인에게만 보임). 끝나면 몇 명이 무엇을 얻었는지 요약돼요.
- **먼저 뜯은 한 명만**: 가장 먼저 뜯은 사람이 가져가고, 결과가 모두에게 공개돼요.
봇을 껐다 켜도 이미 나온 패키지와 상점 버튼은 그대로 동작해요.

**상점.** 구입·판매가 모두 꺼진 물품은 상점에 안 나오고 가방에만 있어요. 상점에는 **최대 25개**(디스코드 선택창 한도)까지 올릴 수 있어요. 구입을 켜면 구입가, 판매를 켜면 판매가가 1 이상이어야 해요. 같은 사람이 버튼을 연타해도 이중으로 결제되지 않아요.

**역할 상점.** 안전을 위해 **관리자·서버 관리·역할 관리·채널 관리·멘션 전체·추방·차단 같은 관리 권한이 있는 역할은 올릴 수 없어요.** 봇의 역할보다 위에 있는 역할, 봇·연동이 관리하는 역할, `@everyone`도 안 돼요. 역할을 주는 데 실패하면 **낸 재화를 바로 돌려드려요**. 역할을 판매할 때는 역할을 거둔 뒤에 재화를 줘요.

**물품 삭제.** 되돌릴 수 없어서 확인 버튼이 나오고, 사람들의 가방에 있던 물품도 함께 사라져요. 던전 입장 물품이나 패키지 결과표가 쓰는 물품은 지울 수 없어요.

## 봇 초대와 권한
- 초대할 때 **`bot`**, **`applications.commands`**를 선택하세요.
- 필요한 권한: **채널 보기, 메시지 보내기, 링크 첨부(임베드), 반응 추가**(선택), 그리고 **역할 관리**(역할 상점을 쓸 때만). 역할 상점을 쓴다면 서버 설정에서 **봇 역할을 판매할 역할들보다 위로** 옮겨 주세요.
- **특권 인텐트(메시지 내용·서버 멤버)는 기본으로는 켤 필요가 없어요.** 단, `/역할재화지급`을 쓰려면 **서버 멤버 인텐트**가 필요해요(아래 *역할 재화 지급*).

## 실행
1. Python 3.10 이상을 설치하고, 개발자 포털에서 봇을 만들어 토큰을 복사해요.
2. **Windows**: `start.bat`을 두 번 클릭 → 처음엔 `.env`가 열려요 → `DISCORD_TOKEN`(과 `GUILD_ID`)을 적고 저장한 뒤 다시 실행.
3. **터미널**: `pip install -r requirements.txt` → `.env.example`을 `.env`로 복사해서 채우기 → `python main.py`.
4. 콘솔에 `서버 ID …: 슬래시 명령어 30개 등록 완료`가 뜨면 성공이에요. `GUILD_ID`를 비우면 모든 서버에 등록되는데 반영까지 최대 1시간 걸려요.

**토큰은 채팅·스크린샷·깃허브에 절대 올리지 마세요.** `.env`와 `data/`는 `.gitignore`에 들어 있어요.

## 데이터
재화·가방·상점 정보는 `data/halloween.sqlite3` 한 파일에 저장돼요. **이 파일을 복사해 두면 백업**이에요(봇을 끈 상태에서). 호스팅을 쓴다면 `data` 폴더가 재시작·재배포 때 유지되는지 꼭 확인하세요. 지워지면 모두의 재화와 가방이 사라져요.

## 알아둘 점
- **경험치(EXP) 기능은 없어졌어요.** 예전 버전에서 쌓인 EXP 숫자는 데이터베이스에 그대로 남아 있지만 어디에도 쓰이지 않아요(지우지 않았어요). 예전 `/이벤트설정`의 경험치 값도 무시돼요.
- 물품 목록은 **서버당 하나**예요. 여러 채널에 상점을 띄우면 모두 같은 목록이 보여요(채널마다 다른 상점은 지원하지 않아요).
- 이모지는 일반 이모지 하나 또는 그 서버의 이모지(`<:이름:ID>`)만 쓸 수 있어요. 서버 이모지는 본문에서는 그림으로 보이지만 선택창 설명에서는 그림으로 안 보여서, 거기서는 재화 이름으로 대신 보여줘요.
- 이름 뒤의 조사(이/가, 은/는)는 받침을 보고 자동으로 붙여요. 영문·숫자로 끝나는 이름은 어색할 수 있어요.
- 봇이 꺼져 있는 동안의 채팅에는 보상이 없어요.

## 검증
자동 시험 **371개**가 통과합니다. 확률은 경계값(정확히 50%, 0.1%, 60/80/90%)과 대량 표본(채팅 2만 번, 패키지 결과 40만 번)으로 확인했고, 재화 상한·판매·역할 환불·연타·관리자 전용·패키지(누구나/선착순)·재시작 후 버튼 등록을 시험해요. 일부러 코드를 망가뜨린 **새 기능 33가지(재화·입장 물품·패키지 결과표·던전 콘텐츠 편집)와 클리어 보상 8가지를 모두 시험이 잡아냈어요.** 한글 옵션 이름이 실제 명령 처리 경로에 제대로 연결되는지, 봇을 켤 때의 시작 순서(확장 불러오기·고정 버튼 등록·서버별 명령어 등록)도 확인했어요.

**직접 확인하지 못한 것**: 실제 디스코드 접속, 화면이 실제로 어떻게 보이는지(임베드·선택창·버튼 배치), 서버 이모지가 선택창에서 보이는지, 봇 권한과 역할 순서에 따른 역할 지급 성공 여부, 재시작 뒤 이미 올라간 버튼이 실제로 응답하는지. **테스트 서버에서 먼저** 위 순서대로 확인해 보세요.
