# 🖥️ 이벤트 봇

이벤트 채널에서 채팅하면 **💾 RAM**(이름·이모지·최대량은 관리자가 바꿀 수 있어요)를 모으고, 가끔 나타나는 **📦 패키지**를 뜯고, **상점**에서 물품과 역할을 사고파는 디스코드 봇이에요.

## 누가 보고 누가 조작하나
- **모든 명령어의 응답은 채널에서 모두가 볼 수 있어요**(관리자 명령어와 오류 안내 포함). 단, **패키지**는 예전 그대로예요: 누구나 뜯을 수 있고 결과는 뜯은 사람에게만 보여요.
- **던전(`/던전`)은 개인 화면이라 본인에게만 보여요.** 입장 불가 안내도, 층·장비·판매 화면도 모두 같아요. 관리자용 던전 명령어(`/던전설정`, `/던전목록` 등)는 다른 명령어처럼 모두가 볼 수 있어요.
- 명령어로 연 화면(가방·던전·확인 버튼 등)은 **연 사람만 조작**할 수 있어요. 다른 사람이 누르면 아무것도 바뀌지 않고, 누른 사람에게만 "연 사람만 조작할 수 있어요"라고 안내해요.
- 상점 패널(채널에 고정된 상점 메시지)은 여러 사람이 함께 쓰는 메시지라서 **물품 상세·가방 버튼의 응답은 누른 사람에게만** 보여요.

## 규칙 한눈에
| 항목 | 내용 |
|---|---|
| 재화 | 기본은 **RAM** 💾, 최대 **9,999,999,999개**(약 99억). `/재화설정`으로 이모지·이름·최대량을 바꿔요 |
| 채팅 보상 | 채팅 한 번에 **50%** 확률로 💾 **1~5**개 |
| 패키지 | 채팅 한 번에 **0.1%** 확률로 그 채널에 나타남. 뜯을지 말지는 각자 선택. 한 번 뜯으면 **30초** 동안은 다른 패키지를 못 뜯어요. 가끔(**35%**) **패키지 더미**로 변이해서 나오고, 더미는 **3개**가 나와요 |
| 패키지 결과 | 기본은 **빈 패킷 39.9%** · 🗝️ 열쇠 14% · 💾 50개 7% · 🗑️ 쓰레기 11% + 팔 수 있는 물품 7종(아래 **패키지 물품과 판매가**) + 🎟️ **부활권 0.1%**(아래 **🎟️ 부활권**). `/패키지결과`로 종류·확률·보상·아이콘을 바꿔요 |
| 상점 | 관리자가 물품·역할을 등록. 물품마다 **구입 true/false**, **판매 true/false** |
| 가방 | `/가방`: 내 재화·물품·가진 역할 |
| 채널 지정 | 재화·패키지는 **관리자가 정한 이벤트 채널에서만** |

## 던전
패키지에서 얻은 🗝️ 열쇠 1개(기본값, `/던전입장물품`으로 바꿀 수 있어요)로 `/던전`에 들어가요. **10층**까지 올라가는 던전이고, 한 층에 방이 **10개**(총 100개)예요. 턴제로 싸워요. HP는 1,000이에요.

**방 배치** (한 층마다 같은 순서예요)
| 방 | 내용 |
|---|---|
| 1·3·5·7·9번째 | 🎁 보급 상자 (장비 1개 + 소모품 1개) |
| 2·4·6·8번째 | 🚪 빈 방 40% · ⚠️ 잡몹 60% |
| 10번째 | 👑 미니 보스 (이기면 **위 층으로 올라가요**. 10층의 보스를 이기면 클리어) |

**층**
- 10번째 방의 보스를 이기고 **[앞으로]**를 누르면 위 층의 1번째 방으로 올라가요. 올라갈 때 **잃은 HP의 절반을 회복**해요(기본값).
- 층이 오를 때마다 **몬스터·보스의 체력과 공격이 1층의 4%씩** 늘어나요. 10층은 1층의 약 1.36배예요. 회피와 내 능력치는 그대로예요.
- **10층의 보스를 이기고 [앞으로]를 누르면 클리어**예요. 층을 올라간다고 보상이 나가지는 않아요(보상은 클리어할 때만).
- 화면 제목에 지금 층과 방이 보여요(예: `3/10층 · 방 4/10`). 상자의 장비·소모품과 장착한 장비는 층을 올라가도 그대로 가져가요.
- 아래 몬스터 수치는 모두 **1층 기준**이에요. 층 수, 층당 강화율, 올라갈 때의 회복량은 `/던전설정`으로 바꿔요.

**전투**
- **공격**: 잡몹은 회피 10%(명중 90%), **고장 난 마우스는 회피 30%**, **보스는 회피 불가(항상 명중)**. 리벳 건·레일건처럼 '회피 확률 변환' 무기는 잡몹에게만 적용돼요(보스에게는 영향 없음).
- **방어**: 가드 성공 확률 기본 60%(방패마다 따로 정할 수 있어요 — 아래 `/장비` 설명). 성공하면 ① 이번 피해를 줄이고(기본 60%, 방패는 더 많이) ② 그 공격 피해의 **50%만큼 HP 회복** ③ 그 공격 피해의 **30%를 몬스터에게 반사**(나무 방패 40%, 방패 50%) ④ **몬스터가 다음 공격을 못 해요**(💫 기절). 실패하면 그대로 맞아요. 회복량이 받은 공격에 비례해서 방어만 반복해도 HP가 불어나지 않아요.
- **아이템 사용**: 전투 중엔 한 턴을 써요. 기절한 몬스터는 그 턴도 공격하지 못해요.
- **상자**: 장비는 **장착 / 예비에 넣기 / 버리기 / 판매** 중에서 정해야 앞으로 갈 수 있어요. 장비·소모품은 그 던전 안에서만 써요. 예비 칸은 아래 **장비 예비 칸**을 보세요.

**장비** (일반 등급 상향) — 낡은 스패너 +30 · 레이저 커터 +35(크리티컬 50%) · 구리 방열판(가드 80%, 반사 40%) / 희귀·전설은 그대로예요.

**몬스터** (원래 수치의 약 90%로 너프)
| | HP | 공격 | 회피 |
|---|---|---|---|
| 🛸 정찰 드론 | 225 | 65 | 10% |
| 🛢️ 오일 슬러지 | 270 | 45 | 10% |
| 🤖 악성 AI | 135 | 135 | 10% |
| 🖱️ 고장 난 마우스 | 90 | 45 | 30% |
| 🖥️ 메인프레임 군주 | 900 | 135 | 0% |
| 🧫 슬러지 코어 | 1,125 | 90 | 0% |
| 👾 스크랩 봇 왕 | 810 | 180 | 0% |

**끝**: 마지막 층(기본 10층)의 보스를 이기고 앞으로 가면 꼭대기에서 클리어할지 **♾️ 무한모드로 계속할지** 물어요. 클리어하면(기본: 💾 50~150 + 10% 확률로 🎟️ 히든 칭호 획득권, 그리고 `/던전보상`으로 정한 추가 물품). 다운되거나 나가면 보상 없이 끝나고 입장에 쓴 물품은 돌아오지 않아요(단, 다운될 때 가방에 🎟️ 부활권이 있으면 한 장을 써서 되살아나요). 안 쓴 장비·소모품은 사라지니 **[💰 판매]**로 미리 팔 수 있어요(아래 **던전에서 팔기**).
**이어하기**: 봇이 꺼지거나 화면을 닫아도 진행(층 포함)은 저장돼요. 층이 생기기 전에 저장된 던전은 1층으로 이어져요. `/던전`을 다시 치면 입장 물품 없이 이어서 해요. 클리어 보상은 한 번만 나가요.
획득권은 `/가방`에 표시돼요(0장이면 안 보여요). **칭호로 바꾸는 기능은 아직 없어서**, 획득권을 쓴 사람이 있으면 관리자가 칭호를 직접 주고 `/획득권지급`으로 그 장수만큼 **회수**해요(최대 99,999장). 위 수치는 **기본값**이에요. 서버 관리자가 디스코드에서 `/던전설정`으로 바로 바꿀 수 있어요(아래 참고). 코드에서 기본값 자체를 바꾸려면 `balance.py` 맨 위를 고쳐요.

## 패키지 물품과 판매가
패키지에서 나오는 물품이에요. 모두 상점 물품 목록에서 팔 수 있고, 판매가를 **음수로 두면 팔 때 재화를 내요**(처리 비용). **범위**로 두면 팔 때마다 그 사이에서 **한 개씩 따로** 뽑아요.

| 물품 | 판매가 | 패키지에서 나올 확률 |
|---|---|---|
| 🔲 구형 CPU | 💾 100 | 5.5% |
| 🧊 방열 패드 | 💾 100 | 5.5% |
| 📺 깨진 디스플레이 파편 | 💾 **-150** (팔면 150을 내요) | 8% |
| 🔌 무정전 전원 장치 | 💾 250 | 3% |
| 💿 실리콘 웨이퍼 | 💾 300 | 1.5% |
| 🧪 액체 냉각제 | 💾 500 | 0.5% |
| 🧰 출처 불명 부품 키트 | 💾 **-300 ~ 300** (팔 때마다 달라요) | 4% |
| 🗑️ 쓰레기 | 💾 **-20 ~ 20** (팔 때마다 달라요) | 11% |

**확률의 원칙:** 값어치가 높을수록 드물게(액체 냉각제가 가장 드물어요), 쓸모없거나 손해인 물품은 흔하게 해 두었어요. 나머지는 빈 패킷 39.9% · 열쇠 14% · 💾 50개 7%이고, 🎟️ 부활권이 0.1%예요. 합계가 100이라 숫자가 곧 퍼센트예요. `/패키지결과 목록`에서 보고 `/패키지결과 수정`으로 바꿔요. 안 팔고 가방에 두면 손해는 없어요.

**🎟️ 부활권 (패키지 0.1%)** — 던전에서 **다운됐을 때 가방에 부활권이 있으면 자동으로 한 장이 쓰여서**, 그 자리에서 다시 일어나요.
- 일어나는 HP는 최대 HP의 **50%**(`/던전설정 일반.부활체력`으로 1~100% 사이에서 바꿔요). 싸우던 상대는 그대로라서 이어서 싸워요.
- 한 번 다운될 때마다 한 장씩 써요(여러 장이면 여러 번 살아나요). 없으면 전과 같이 던전이 끝나요. 따로 누를 버튼은 없어요.
- 팔거나 살 수 없는 물품으로 만들어져요(`/물품수정`으로 바꿀 수 있어요). 확률은 `/패키지결과 수정`으로 바꿔요. 더미(결과 3개)에서는 3번 각각 0.1%예요.

**음수·범위 판매가의 안전장치**
- 팔 때 재화를 내는 물품은 **낼 재화가 있어야** 팔 수 있어요. 범위라면 **가장 나쁜 경우**(예: 병 한 개에 300)를 기준으로 봐서, 모자라면 아무것도 팔리지 않아요. 그래서 운이 좋을 때까지 다시 눌러 보는 일은 못 해요.
- 가장 좋은 경우에 최대 보유량을 넘길 수 있어도 팔리지 않아요(물건이 사라지지 않게).
- 여러 개를 한 번에 팔면 개수만큼 따로 뽑아서 더해요.

**기본 확률표 적용하기:** `/패키지결과 기본값`을 치면 지금 결과표를 위 기본 확률표(12칸)로 **통째로 바꿔요**. 바꾸기 전에 어떻게 바뀌는지 보여 주고 [바꾸기] 버튼을 눌러야 적용돼요. 직접 바꾼 확률·이름·아이콘은 기본값이 돼요. 열쇠·쓰레기·새 물품 7종·부활권 중 **없는 것만 만들고**, 있는 물품의 이름·가격은 그대로예요. 가방·재화·상점·던전 설정은 바뀌지 않아요. 쓰레기의 판매가(-20~20)는 `/물품수정`으로 따로 고쳐요.

**판매가 바꾸기:** `/물품수정 물품:쓰레기 판매가:-5 판매최대:5`처럼 판매가와 `판매최대`를 함께 적어요. 판매가와 판매최대를 같은 값으로 적으면 다시 고정값이 되고, 판매가를 올릴 때는 `판매최대`도 같이 올려야 해요.

**이미 운영 중인 서버:** 업데이트 뒤 처음 열릴 때 **한 번만** 아래처럼 이전돼요. 가방·지갑·상점은 그대로예요.
- 물품 7종이 만들어지고, 아직 손대지 않은 🗑️ 쓰레기는 판매가 -20~20으로 팔 수 있게 돼요(이미 판매를 켜 둔 쓰레기는 그대로).
- 패키지 결과표는 **예전 기본값 그대로일 때만** 위 확률표로 자동으로 바뀌어요. 관리자가 확률을 바꿔 둔 서버는 표를 건드리지 않아요(물품만 만들어 둬요). 이런 서버는 아래 `/패키지결과 기본값`으로 직접 적용하세요.
- 같은 이름의 물품을 이미 만들어 뒀다면 그 물품을 그대로 쓰고 값은 바꾸지 않아요.
- **🎟️ 부활권(0.1%)**: 물품이 만들어지고 결과표에 들어가요. 예전 기본값 그대로인 표는 빈 패킷에서 0.1을 덜어 합 100에 정확히 0.1%가 되게 하고, **관리자가 바꿔 둔 표도 다른 칸의 비율은 그대로 두고** 부활권 한 칸만 0.1% 몫으로 덧붙여요(칸이 20개로 가득 찼으면 못 넣어요).
- 상점은 25칸이 한도라서, 자리가 모자라면 남은 물품은 **판매가 꺼진 채** 만들어져요. `/물품수정`으로 켜세요.

## 연금술
가방의 물품 **2~3개**를 합쳐서 새 물품을 얻어요. `/연금술`을 치고, 재료를 고르고(셋째 칸은 선택), **[⚗️ 합성]**을 눌러요. 합성하면 같은 메시지가 결과로 바뀌어요.

- **열리는 시간:** 현실 시간(한국 시간)으로 **매일 오후 6시부터 자정(오전 12시)까지**예요. 18:00:00부터 열리고, 자정이 되는 순간 닫혀요. 닫혀 있을 때는 언제 열리는지 알려 주고 [합성]을 눌러도 합성되지 않아요(화면을 일찍 열어 뒀어도 마찬가지예요).
- **레시피:** 관리자가 `/연금술레시피 추가`로 직접 더해요. **기본으로 들어 있는 레시피는 없어요.** 재료의 **순서는 상관없고**, 같은 물품을 두 번 쓰는 레시피(예: 마나 가루 2개)도 돼요. 레시피에 없는 조합이면 "그런 조합의 레시피는 없어요"라고 알려 주고 **재료는 그대로 남아요**. 재료가 모자라도 아무것도 줄어들지 않아요.
- **레시피 비공개:** 플레이어 화면에는 레시피 내용이 나오지 않아요(가방에서 재료로 쓰이는 물품만 보여요). 레시피는 관리자의 `/연금술레시피 목록`에서만 볼 수 있어요.
- **합성물의 판매가:** 재료들의 **판매가를 전부 더한 값**에 **두 개를 합쳤다면 ×0.8, 세 개를 합쳤다면 ×0.6**을 곱해요(반올림). 예: 판매가 100 + 100 → (100+100)×0.8 = **160**, 100 + 100 + 300 → 500×0.6 = **300**. 레시피를 더하는 순간 결과물의 판매가가 정해져 바로 적용되고, 판매도 켜져요(상점 25칸이 차 있으면 가격만 정해지고 판매는 꺼져 있어요).

**관리자: 레시피 만들기**
1. 결과물과 재료로 쓸 물품을 먼저 만들어 둬요(`/물품등록`).
2. `/연금술레시피 추가 결과물:고급 부품 재료1:구리선 재료2:땜납` — 이름은 자동완성에서 골라요. 더하면 계산식(`💾 160 = (100 + 100) ×0.8`)이 나와요.
3. `/연금술레시피 목록`으로 확인하고, `/연금술레시피 삭제 결과물:마력 약`으로 지워요. 지워도 결과물 물품과 그 판매가는 그대로 남아요.

**규칙과 안전장치**
- 재료로 쓰려면 **판매가가 1 이상의 고정값**이어야 해요. 음수·0·범위 판매가(예: 쓰레기, 깨진 디스플레이 파편, 출처 불명 부품 키트)는 값을 정할 수 없어서 재료가 될 수 없어요.
- **한 물품에 레시피는 하나**만 둘 수 있고, **같은 재료 구성(순서 무관)은 한 번만** 쓸 수 있어요.
- **합성물을 다시 재료로 쓸 수는 없어요**(결과물은 재료가 될 수 없고, 재료는 결과물이 될 수 없어요).
- 결과물의 판매가는 **재료의 판매가에 맞춰 자동으로 다시 계산돼요**: 재료의 판매가를 `/물품수정`으로 바꾸면 그 재료를 쓰는 레시피의 결과물 판매가도 바로 따라가요. 결과물의 판매가는 레시피가 있는 동안 직접 바꿀 수 없어요(먼저 레시피를 지우세요). 재료를 음수·범위 판매가로 바꾸는 것도 막혀요.
- 레시피에 쓰이는 물품은 레시피를 지우기 전에는 `/물품삭제`가 안 돼요.
- 서버마다 레시피는 최대 100개예요.
- 같은 버튼을 연타해도 한 번만 합성돼요.
- ⚠️ 판매가에 0.8·0.6을 곱하는 규칙이라 합성물은 **재료를 따로 파는 것보다 낮을 수 있어요**(100+100을 따로 팔면 200, 합성물은 160). 재료 가격 차이가 크면(예: 1000과 1) **가장 비싼 재료보다도 낮아질** 수 있어서, 이런 레시피를 더하면 경고가 나와요.

## 가방에서 팔기
`/가방`(또는 상점의 [가방] 버튼) 아래의 **💰 팔 물품을 골라요** 선택창에서 팔 수 있는 물품을 고르고, 나오는 입력창에 수량을 적으면 바로 팔려요. 팔고 나면 같은 가방 메시지가 새 내용(재화·물품)과 결과로 바뀌어요.
- 선택창에는 **가방에 있고 판매가 켜진 물품**만 나와요(최대 25개). 개당 판매가가 같이 보여요.
- 팔 때 재화를 내는 물품이나 판매가가 범위인 물품도 **상점에서 파는 것과 똑같은 규칙**이에요(위 **패키지 물품과 판매가**).
- 역할은 가방에서 팔지 않고 상점에서 팔아요.

## ♾️ 무한모드 (10층을 깬 뒤 계속하기)
**마지막 층(기본 10층) 보스를 이기고 앞으로 가면**(시크릿 방이 열렸다면 그 뒤에) 바로 클리어되지 않고 **🏔️ 꼭대기 화면**에서 묻는 버튼이 나와요.
- **[🏆 클리어하고 끝내기]**: 예전처럼 던전을 클리어로 끝내고 클리어 보상(재화·🎟️ 획득권 확률·`/던전보상` 추가 물품)을 받아요.
- **[♾️ 무한모드 계속]**: **클리어 보상을 지금 바로 받고**(그 뒤에 다운돼도 잃지 않아요) 11층으로 올라가 계속해요. 11층, 12층…은 끝이 없고, 몬스터·보스는 층마다 계속 강해져요(`일반.층당강화`). 위 층으로 올라갈 때 잃은 HP 일부 회복은 그대로예요.
- **층 보너스**: 무한 층에 오를 때마다 재화를 받아요. 11층은 기본 💾 30, 한 층 오를 때마다 10씩 늘어요(12층 40, 13층 50 …). 재화 최대 보유량을 넘는 만큼은 받지 못해요.
- 무한모드에서 **다운되거나 나가면** 던전이 끝나지만 이미 받은 클리어 보상과 층 보너스는 그대로예요. 끝 화면에 **어느 층까지 올랐는지**가 나와요. 무한 층의 보스를 이긴 뒤에도 시크릿 방이 열릴 수 있어요. 한 번 무한모드를 고르면 다시 묻지 않아요.
- 꼭대기에서 고르기 전에도 **[판매]·[장비]·아이템 사용·나가기**를 할 수 있어요(고르면 장비·소모품은 이어서 가지고 가요).
- **관리자 설정**(`/던전설정`): `일반.무한모드`(1=묻기, 0=묻지 않고 예전처럼 바로 클리어), `무한.층보너스`(기본 30), `무한.보너스증가`(기본 10).
- **빠른진행**은 꼭대기에서 **언제나 클리어하고 끝내요**(무한모드는 위험이 커서 직접 고르세요). 시뮬레이터도 꼭대기를 클리어로 세요.

| 패키지 결과 | `/패키지결과 대량삭제` |
| 클리어 보상 | `/던전보상 대량삭제` |
| 물품 | `/물품대량삭제` (가방에 있던 것도 사라져요) |

- **쓰는 법:** 명령어를 치면 선택 메뉴가 나와요. 지울 것을 **여러 개 체크**하고(25개씩 쪽으로 나뉘고 **◀ ▶**로 넘겨요. 다른 쪽에서 고른 것도 기억해요), 필요하면 **[전체 선택] / [선택 해제]**를 쓰고, **[삭제]**를 누르면 **지울 목록을 한 번 더 보여 주는 확인 화면**이 나와요. 거기서 [삭제]를 눌러야 지워지고, [돌아가기]로 다시 고르거나 [취소]하면 아무것도 지워지지 않아요. 연 관리자만 누를 수 있고, 5분 안에 안 하면 자동으로 닫혀요(아무것도 안 지워져요).
- **못 지우는 것은 건너뛰어요.** 한 개씩 지울 때와 같은 규칙이 그대로 적용돼요(다른 설정이 쓰는 장비·물품, 마지막 하나 남은 보스·패키지 결과 등). 결과 화면에 **지운 것과 못 지운 것(이유 포함)**을 나눠서 보여 줘요. 같이 고른 것 때문에 막혀 있던 것(예: 개조 레시피에 쓰이는 장비 + 그 레시피)은 먼저 레시피가 지워진 뒤에 자동으로 다시 시도해요.
- 이름에 쉼표가 있어도 안전해요(글자를 이어 적는 방식이 아니라 메뉴에서 골라요).
- `/소모품조건`의 조건은 한 번에 모두 떼는 `비우기`가 이미 있어서 따로 만들지 않았어요.

## 긴 목록 넘겨 보기 (◀ ▶)
장비·소모품이 많아져도 목록이 **잘리지 않아요.** 디스코드는 한 칸에 1024자까지, 선택 메뉴에 25개까지만 담을 수 있어서, 넘치면 **쪽으로 나누고 ◀ ▶ 버튼**으로 넘겨 봐요(연 사람만 누를 수 있어요).
- **`/던전목록`**(몬스터·보스·장비·소모품·시크릿 보스): 칸이 길면 여러 칸으로 나눠 담고, 한 화면(임베드)이 넘치면 다음 쪽으로 넘어가요. 분류를 고르면 그 분류만 봐요.
- **`/장비개조 목록`**, **`/소모품조건 목록`**: 길면 쪽으로 나눠요.
- **던전 안 [💰 판매] 화면**: 팔 수 있는 게 25개를 넘으면 **쪽으로 나뉘고**(이전엔 앞의 25개만 보였어요) ◀ ▶로 넘겨요. **다른 쪽에서 고른 것도 기억**해서 함께 팔 수 있어요.
- **던전 안 아이템 메뉴**: 소모품 종류가 25개를 넘으면 `아이템 이전 / 아이템 다음` 버튼이 생겨요. 소지품 칸이 너무 길면 `… 외 N종`으로 줄여 보여 줘요.
- 자동완성(이름 고르기)은 디스코드 규칙상 25개까지만 보여 줘요. 글자를 입력해 좁히면 나머지를 찾을 수 있어요.

## 🧥 갑옷 (받는 피해를 줄이는 세 번째 장비)
무기·방패와 따로 **갑옷 칸**이 하나 있어요. 입고 있는 동안 **몬스터에게 받는 모든 피해를 %만큼** 줄여요(가드 성공·실패와 상관없이 늘 적용).

- **계산 순서:** 몬스터 공격 → **갑옷** → 소모품 `피해감소` 순으로 곱해서 줄어요(무적이면 0). 단, **방어(가드)에 성공한 공격에는 방패(가드)의 피해 감소만 적용돼요** — 갑옷과 소모품 피해 감소는 빠져요. 가드에 실패하거나 방어를 안 했을 때는 갑옷·소모품 감소가 그대로 적용돼요.
- **만들기:** `/장비 추가 종류:갑옷 피해감소:25 …` (1~90%. 갑옷에는 `피해감소`가 필수예요). 고치기는 `/장비 수정 피해감소:`. `등장`·`판매가`·`/장비 층`(나올 층)·`/장비지급`은 다른 장비와 똑같아요.
- **얻기·바꾸기:** 상자에서 나오면 무기·방패와 같이 **장착 / 예비에 넣기 / 버리기**를 골라요. 예비 갑옷 칸이 1개 있고, `🎒 장비` 화면의 **[갑옷 교체]**로 바꿔요. 던전 화면에는 입은 갑옷이 보이고, 팔 수도 있어요(장착 중/예비/새 장비).
- **개조:** `/장비개조 추가`에서 갑옷은 갑옷으로만 바뀌어요(예: `방진 커버 + 수선 도구 → 강철 갑옷`). 개조 재료를 쓸 때 든 장비 순서는 무기 → 방패 → 갑옷이에요.
- **기본 갑옷 3개:** 🧥 방진 커버(일반, 5%) · ⛓️ 합금 장갑(희귀, 8%) · 🦾 나노 복합 장갑(전설, 12%). 수치는 `/장비 수정 대상:방진 커버 피해감소:10`으로 바꾸고, 마음에 안 들면 `/장비 삭제`로 지워도 돼요. **이미 `/장비`로 장비를 직접 편집한 서버는 저장된 목록을 그대로 쓰니 기본 갑옷이 새로 생기지 않아요**(`/장비 추가`로 만들거나 `/던전콘텐츠초기화`).
- 기본 갑옷은 시뮬레이션 기준으로 던전 난이도가 크게 달라지지 않게 작은 값으로 잡았어요. 강하게 하고 싶으면 `피해감소`를 올리세요(무한모드와 함께면 더 쉬워져요).
- 빠른진행(컴퓨터)은 피해 감소가 더 큰 갑옷만 입고, 아니면 버려요.

## 🪤 함정 방과 커스텀 방
방 배치(한 층의 1~10번째 방)에 **함정 방**과 관리자가 만든 **커스텀 방**이 섞여 나올 수 있어요. 둘 다 **들어서자마자** 효과가 일어나고, 그다음엔 평소처럼 [앞으로]로 갈 수 있어요(싸움이 없어요).

**함정 방** — 들어서면 피해를 입어요. 막을 수 없어요(가드는 못 씀). 다만 **갑옷, 소모품의 피해 감소, 무적은 적용**돼요. 피해는 몬스터처럼 층마다 늘어나요(`일반.층당강화`). 함정에 다운되면 던전이 끝나고, 가방에 부활권이 있으면 그 자리에서 되살아나요.
- **기본은 꺼져 있어요**(확률 0%): 업데이트해도 기존 서버의 난이도와 방 추첨이 그대로예요. 켜려면 `/방 함정확률 퍼센트:10` → 2·4·6·8번째 방(빈 방·잡몹이 섞이는 방)에서 함정이 나올 확률이 10%가 돼요(다른 방과의 비율로 계산하고, 소수도 돼요). 방마다 따로 정하려면 `/던전설정 방N.함정`(가중치).
- 피해는 `/방 함정피해 피해:150`(1층 기준, 기본 100). `/던전설정 함정.피해`와 같은 값이에요. 값 없이 쓰면 지금 설정을 보여 줘요.

**커스텀 방** — `/방 추가 이름 이모지 [문구] [가중치] [피해] [회복] [재화] [소모품] [소모품개수] [방번호] [층]`
| 옵션 | 뜻 |
|---|---|
| `문구` | 들어서면 보이는 글(300자까지). 문구만 있어도 돼요(이야기 방). 문구나 효과 중 하나는 있어야 해요 |
| `가중치` | 방 배치의 다른 방(상자·빈방·잡몹…)과 **같은 단위**로 겨뤄요(소수 가능, 기본 10). 빈 방 40·잡몹 60인 방에 10을 주면 약 9% |
| `피해` / `회복` | 들어서면 먼저 피해(갑옷·피해 감소·무적 적용, 다운될 수 있어요), 이어서 HP 회복 |
| `재화` | 얻는 재화. 다음 지급 때 바로 들어와요(재화 최대 보유량 안에서) |
| `소모품` + `소모품개수` | 소지품에 들어가요(소모품 사용 조건 `아이템 획득`에도 걸려요) |
| `방번호` | 나올 방: `3,5,8-9`처럼. **1~9번째만**(10번째는 보스 방). 비우면 1~9번째 모두 |
| `층` | 나올 층: `3,5,8-10`. 비우면 모든 층 |

- `/방 수정`은 바꿀 것만 적고, `문구`·`소모품`에 `-`를 쓰면 지워요. `/방 삭제`, `/방 대량삭제`(여러 개 골라 지우기)도 있어요. 방을 만들면 `/던전목록`에 **커스텀 방** 칸이 생겨요. `/던전콘텐츠초기화`로 모두 지울 수 있어요.
- 최대 30개. 기본 방 배치에서 상자만 나오는 홀수 방(1·3·5·7·9번째)도 커스텀 방이 나올 수 있게 정하면 그 방부터는 추첨을 해요.
- 빠른진행(컴퓨터)은 이 방들을 그냥 지나가요. 시뮬레이터(`/던전시뮬`)에는 함정과 커스텀 방의 피해·회복·소모품이 반영돼요.

## 🛒 상점 (5층마다)
**5층, 10층, 15층…의 보스를 이기고(시크릿 보스를 이겼다면 그 뒤에) 위 층으로 올라가기 직전**에 상점이 한 번 열려요. 같은 층에서는 다시 열리지 않아요.

- **상품 3개:** 그 층에서 나올 수 있는 장비와 소모품(`/장비 층`·`/소모품 층` 제한을 따르고, `등장` 비율이 0이면 안 팔아요) 중에서 서로 다른 3개가 놓여요. 상품마다 장비/소모품은 반반이고, 그 안에서는 **상자와 같은 `등장` 비율**대로 골라요(소수 가능, 이미 놓인 상품은 빼고). 그래서 흔한 것이 자주 나오고 희귀·전설은 가끔 나오며, 비율을 0으로 한 것은 안 팔아요. 팔 만한 게 없으면 상점이 열리지 않아요.
- **가격:** 기본은 그 물건의 판매가 × `상점.가격배율`(기본 400% = 4배)이에요. 판매가가 0인 것은 등급 기본 판매가(일반 5·희귀 15·전설 50)로 계산해서 일반 20 · 희귀 60 · 전설 200이에요. **물건마다 따로 정할 수도 있어요**: `/장비 추가·수정`, `/소모품 추가·수정`의 `상점가`(1 이상)를 쓰면 그 값이 그대로 상점 가격이에요(갑옷·개조 재료 포함). 수정에서 `-1`이면 자동 계산으로 되돌려요. `/던전목록`에는 정한 것만 `상점가`가 보여요. 가격은 상점이 열릴 때 정해져서 중간에 설정을 바꿔도 안 변해요.
- **사는 법:** 던전 화면의 상품 버튼(이름 + 가격)을 누르면 **지갑의 재화**로 사요. 모자라면 아무것도 안 바뀌어요. 산 소모품은 소지품에, 산 장비는 상자에서 나온 것처럼 **장착 / 예비에 넣기 / 버리기**를 정해요(장비를 정하기 전에는 다른 장비를 못 사요). 던전 안에서 장비·소모품을 **팔아서** 재화를 만든 다음 살 수도 있어요.
- **나가기:** [상점 나가기]를 누르면 위 층으로 올라가요. 마지막 층(10층)에서는 상점을 지나야 클리어/무한모드 선택이 나와요(무한모드를 꺼 두면 마지막 층엔 상점이 없어요). 무한모드의 15·20…층에도 열려요.
- **설정:** `/던전설정 상점.간격`(기본 5, **0이면 상점이 없어요**), `/던전설정 상점.가격배율`(기본 400).
- 빠른진행(컴퓨터)은 상점에서 아무것도 사지 않고 지나가요. `/던전시뮬`은 상점을 열지 않아서 난이도 어림값이 그대로예요.

## 🔷 속성 상성 (관리자)
관리자가 **속성을 직접 만들고**, 어느 속성이 어느 속성에 강한지 **피해 배율(%)**로 정해요. 기본으로는 속성이 하나도 없어서 지금까지와 똑같아요.

1. `/속성 추가 이름:전기 이모지:⚡` — 속성을 만들어요(최대 20개).
2. `/속성 상성 공격:전기 방어:냉각 배율:150` — 전기가 냉각을 때리면 **1.5배**. 50이면 절반, 0이면 피해 없음, 100이면 기본으로 되돌려요(0~1000%). 정하지 않은 조합은 100%예요. 방향이 따로라서 `냉각 → 전기`도 따로 정해요.
3. `/속성 지정 대상:레이저 커터 속성:전기` — 붙이기(`-`면 떼기). 대상은 자동완성에서 골라요.
   - **무기** = 내 공격 속성, **갑옷** = 몬스터 공격을 받을 때의 방어 속성, **몬스터·보스·시크릿 보스** = 그 몬스터의 속성(때릴 때도 맞을 때도). **방패에는 속성이 없어요.**
4. `/속성 목록` — 속성마다 붙은 개수와 상성표를 봐요. `/속성 삭제`로 지우면 붙어 있던 것은 무속성으로 치고 상성표에서도 빠져요.

- **내 공격:** (기본 공격 + 무기) → 크리티컬(2배) → **속성 배율** 순서예요. 화면에 `🔺 상성 우위! (×1.5)` / `🔻 상성 열세 (×0.5)`가 떠요.
- **몬스터의 공격:** 몬스터 공격력 × **(몬스터 속성 → 내 갑옷 속성) 배율** → 가드·갑옷 감소 등 지금까지의 계산. 가드 회복·반사는 원래 공격력 기준이에요.
- 소모품 피해·지속 피해·함정·커스텀 방 피해에는 속성이 없어요.
- 전투 화면에 몬스터 이름 옆 `[⚡ 전기]`, 장비 칸에 무기·갑옷의 속성이 보여요. `/던전목록`에도 붙은 속성이 보여요.

## 📢 공지 (관리자)
`/공지`를 쓰면 **제목(비워도 됨)·내용**을 적는 입력창이 떠요. 보내면 고른 채널에 **봇이 직접 쓴 새 메시지**로 공지가 올라가요. 입력창은 메시지 없이 닫혀서 "누가 명령어를 썼다"는 흔적이 채널에 남지 않아요.
- `채널`: 공지를 올릴 채널(비우면 지금 채널) · `형식`: **카드(임베드, 기본)** 또는 **일반 글** · `멘션`: 없음 / @everyone / @here · `역할`: 함께 멘션할 역할 · `그림`: 붙일 그림 주소(http/https)
- 카드는 내용 4,000자까지, 일반 글은 멘션·제목·내용을 합쳐 2,000자까지예요(디스코드 한도). 입력창에서는 줄바꿈도 그대로 들어가요.
- 카드 아래에는 `📢 (서버 이름) 공지`와 올린 시각이 붙어요.
- 멘션은 고른 것만 실제로 울려요(공지 내용 안에 적힌 @everyone 같은 글자로는 울리지 않아요).
- 봇이 그 채널에 글쓰기·링크 첨부(카드)·@everyone 멘션(멘션을 고른 경우)·역할 멘션 권한이 없으면 입력창을 띄우기 전에 무엇이 모자란지 알려 줘요. 이때와 오류가 났을 때만 안내가 채널에 남아요.
- 누가 언제 어느 채널에 공지했는지는 봇 로그에 남아요.

## 🌌 시크릿 보스 (11번째 방)
**보스를 이기고 올라갈 때 10% 확률로**(기본값) 그 층에 **11번째 방(시크릿 방)**이 열리고, 시크릿 보스가 나타나요. 마지막 층에서도 클리어 직전에 열릴 수 있어요. 확률은 **`/시크릿보스 확률 퍼센트:`**로 보고 바꿔요(소수 가능, 0이면 안 열려요, 비우면 지금 확률과 '한 판에 한 번 이상 열릴 확률'을 보여 줘요). `/던전설정 일반.시크릿확률`로 바꿔도 같은 값이에요. 시크릿 방은 피할 수 없는 싸움이라 확률이 높을수록 던전이 어려워져요. 한 번 이긴 뒤 올라갈 때 또 추첨하지는 않아요.
- **드롭: 장비와 아이템 중 하나는 반드시 나와요.** 시크릿 보스마다 **드롭 장비**와 **드롭 아이템**(+개수)을 정하고, 각각 **확률(소수 가능)**로 굴려요. 둘 다 안 나오면 **확률이 더 높은 쪽이 강제로 나와요**(같으면 장비). 드롭 장비·아이템 중 하나는 꼭 있어야 하고, 한쪽이 없어졌다면(지워졌다면) 남은 쪽이 나와요. 드롭 장비는 상자처럼 **장착 / 예비에 넣기 / 버리기**를 정해야 앞으로 갈 수 있고, 아이템은 소지품에 들어가요.
- **연출:** 시크릿 방이 열리면 같은 메시지가 **6장면으로 바뀌며** 등장해요 — 어둠 → 짙어지는 공기 → ⚠️ WARNING → 가려진 이름(？？？) → 이름이 절반쯤 드러남 → 🌌 SECRET BOSS 『이름』 + 등장문구(+그림). 장면마다 색이 달라 번쩍이는 느낌이에요. **빠른진행 중에도** 똑같이 보여요. 전투 화면은 금색 🌌 시크릿 방 테마예요.
- **나올 층 정하기:** `/시크릿보스 층 대상 층:3,5,8-10`처럼 이 시크릿 보스가 **나올 층을 여러 개** 정해요(쉼표로 여러 층, `8-10`처럼 범위, `전체`는 모든 층, 층을 비우면 지금 설정만 보여 줘요). 그 층의 보스를 이기고 올라갈 때만 시크릿 방이 열릴 수 있고(확률은 그대로 `/시크릿보스 확률`), 기본은 **모든 층**이에요. 시크릿 보스가 여럿이면 그 층에 나올 수 있는 보스들 중에서 `등장` 비율로 골라요. 나올 수 있는 보스가 없는 층에서는 시크릿 방이 열리지 않아요. 11층 이상은 무한모드에서만 갈 수 있어요(무한 층도 정할 수 있어요). `/던전목록`의 시크릿 보스 분류에 보스마다 나오는 층이 보여요.
- **그림/움직이는 gif:** 시크릿 보스마다 `그림`에 주소(http/https)를 적으면 마지막 등장 장면과 전투 화면에 붙어요. **gif 주소를 쓰면 움직여요.** (디스코드 메시지는 직접 만든 애니메이션 코드를 실행할 수 없어서, 연출은 '메시지를 차례로 고치기' + 'gif 그림'으로 해요.)
- **명령어:** `/시크릿보스 추가 이름 이모지 체력 공격 [드롭장비] [장비확률] [드롭아이템] [아이템확률] [아이템개수] [등장] [등장문구] [그림] [빈드롭확률]` · `수정`(바꿀 것만, 드롭장비·드롭아이템·등장문구·그림은 `-`를 적으면 지워요) · `삭제`(모두 지우면 시크릿 방이 안 생겨요). 시크릿 보스가 여럿이면 `등장` 비율(소수 가능)로 골라요. 목록은 `/던전목록`의 시크릿 보스 분류에서 봐요. 기본으로 **🕳️ NULL 군주**(체력 1200 · 공격 150, 드롭: 🔫 레일건 50% · 💽 마스터 리부트 칩 60%)가 하나 있어요. 기본 확률 10%에서도 던전 난이도가 크게 달라지지 않게(시뮬레이션 기준) 일반 보스급으로 맞춰 둔 값이에요. 지운 뒤 `/던전콘텐츠초기화`로 되살릴 수 있어요.
- **빈 드롭 확률(`빈드롭확률`):** 무력화해도 **아무것도 떨어뜨리지 않을 확률(%)**이에요(소수 가능, 기본 0). 먼저 이 확률을 굴려서 걸리면 드롭이 없고, 안 걸리면 예전처럼 장비·아이템을 각자 확률로 굴려 **둘 다 안 나와도 하나는 반드시** 줘요. 100이면 늘 빈손이에요. `/던전목록`에 `드롭(N% 확률로 없음, …)`으로 보여요. 이 업데이트 전에 시작한 시크릿 보스 싸움은 0%로 쳐요.
- 체력·공격은 다른 보스처럼 층이 오를수록 강해져요. 드롭 장비·아이템이 **그 보스의 마지막 드롭이라면 지울 수 없어요**(먼저 다른 드롭을 정하거나 보스를 지워 주세요).

## ⏩ 빠른진행 (컴퓨터가 알아서 진행)
던전에 들어간 뒤 던전 화면의 **[⏩ 빠른진행]** 버튼을 누르고 **입장 물품을 한 번 더 내면**(기본 🗝️ 열쇠 1개) 컴퓨터가 알아서 던전을 진행해요. 화면이 **라이브로** 계속 바뀌고, **[⏹ 멈추기]**를 누르면 언제든 직접 진행으로 돌아와요.
- **비용은 한 던전에 한 번만.** 껐다 켜도(또는 봇이 꺼졌다 켜져도) 같은 던전에서는 다시 안 내요. 입장 물품이 무료로 설정돼 있으면 빠른진행도 무료예요. 켜기 전에 확인 화면이 나오고, 물품이 모자라면 아무것도 바뀌지 않아요.
- **컴퓨터가 하는 일:** 상자를 열고, **더 좋은 장비만 장착**하고(아닌 건 버려요), 평소엔 공격하다가 HP가 60% 아래면 방어하고, 위험하면 회복 아이템을 쓰고, 싸움 밖에서 HP가 많이 빠졌으면 회복 아이템을 알뜰히 써요. 지금 쓸 수 있는 개조 소모품·재료는 **무기가 더 강해질 때만** 써요. 부활권은 평소처럼 다운될 때 자동으로 쓰여요.
- **하지 않는 일:** 장비·소모품을 **파는 일**(필요하면 멈추고 직접 파세요), 조건이 안 맞는 소모품 쓰기. 컴퓨터는 최선을 다하지만 **다운될 수 있어요.** 내장 시뮬레이터로 기본 설정을 40판 돌렸을 때 40~55%가 클리어였어요(표본이 작아 오차가 커요. 부활권 없이, 실제 서버 설정에 따라 달라요).
- **진행 중에는** 버튼이 [⏹ 멈추기] 하나뿐이고, 서버도 사람이 누르는 다른 행동(나가기만 빼고)을 받지 않아요. 나가기는 오래된 화면에서라도 누를 수 있어요.
- **속도·시간:** 1.6초에 한 걸음씩 진행해요(기본 설정에서 한 판은 평균 약 280걸음, 8분쯤). 디스코드는 버튼을 누른 지 15분이 지나면 그 메시지를 더 고칠 수 없어서, **14분이 되면 자동으로 멈추고** 직접 진행 화면으로 돌아와요. ⏩를 다시 누르면 이어서 해요(입장 물품은 안 내요).
- **봇이 꺼졌다 켜졌거나 연결이 끊기면** 빠른진행은 꺼진 상태로 던전이 그대로 남아요. `/던전`으로 이어서 하고, 다시 켜도 비용은 없어요. 빠른진행이 돌고 있을 때 `/던전`을 열면 멈추기 화면이 나와요.

## 💣 소모품 새 효과 (피해·지속 피해·자해·무적·피해 감소)
`/소모품 추가`와 `/소모품 수정`의 옵션으로 정해요. 회복과 함께 붙일 수 있고, 서로 합쳐도 돼요(예: 피를 내고 크게 때리는 소모품). 수정에서 `0`을 쓰면 그 효과가 없어져요. `/소모품조건`의 사용 조건도 그대로 함께 쓸 수 있어요.

| 옵션 | 효과 |
|---|---|
| `몬스터피해` | 쓰면 싸우는 몬스터에게 바로 그만큼 피해. 이걸로 다운되면 몬스터는 반격하지 않아요(시크릿 보스 드롭도 나와요) |
| `지속피해` + `지속피해턴` | 몬스터에게 턴마다 피해(독·화상). 다시 쓰면 쌓이지 않고 새로 시작해요 |
| `자해` (+ `자해턴`) | 쓰면 내 HP가 줄어요. `자해턴`이 2 이상이면 첫 번째는 바로, 나머지는 턴마다. **HP 1 밑으로는 줄지 않아서 이것만으로 죽지는 않아요** |
| `무적턴` | 그 턴 수 동안 몬스터의 공격 피해를 받지 않아요. 쓴 바로 그 턴의 반격도 막아요 |
| `피해감소` + `피해감소턴` | 그 턴 수 동안 받는 피해를 %만큼 줄여요. **가드에 성공한 공격에는 적용되지 않고**(방패의 감소만 적용) 가드 실패·방어 안 함일 때만 적용돼요. 무적이 있으면 무적이 우선이에요 |

- 몬스터에게 쓰는 소모품(`몬스터피해`·`지속피해`)은 **싸우는 중에만** 쓸 수 있어요. 아닐 때는 쓰지 않은 것으로 치고 소모되지 않아요. 아이템 메뉴에서는 쓸 수 있으면 ✨, 아니면 🔒로 보여요.
- 턴은 **싸우는 중에만** 지나가요. 싸움 밖에서 써 두면 다음 싸움 때까지 남아 있어요. 던전 화면의 **🌀 효과** 칸에 남은 턴이 보여요.
- 컴퓨터(빠른진행)와 `/던전시뮬`은 회복 아이템만 써요. 피해·자해 소모품은 직접 써야 해요.

## 조건부 소모품과 무기 개조
소모품마다 **사용 조건**을 붙이면, 조건을 **전부 만족할 때만** 쓸 수 있어요(AND). 조건이 없으면 지금처럼 언제나 쓸 수 있어요. 던전의 아이템 메뉴에 ✨(지금 쓸 수 있음) / 🔒(아직 조건 불만족)로 표시되고, 🔒인 걸 누르면 어떤 조건이 모자란지 알려 주며 **소모품은 줄어들지 않아요.**

**조건 종류** (`/소모품조건 추가`의 `조건`)
| 종류 | 값 | 언제 참인가 |
|---|---|---|
| 내 HP N% 이하 / 이상 | 0~100 | **지금** 내 HP가 최대 HP의 N% 이하/이상 (딱 N%도 포함) |
| 몬스터 HP N% 이하 / 이상 | 0~100 | **지금** 싸우는 몬스터의 HP가 그 몬스터 최대 HP의 N% 이하/이상 (싸우는 중이 아니면 거짓) |
| 방어 성공 / 실패 직후 | – | **바로 직전 행동**이 방어였고 가드에 성공/실패했을 때 |
| 반사 성공 / 실패 직후 | – | 반사 피해는 가드에 성공하면 항상 들어가므로 **가드 성공 = 반사 성공, 가드 실패 = 반사 실패**예요 |
| 공격 적중 / 빗나간 직후 | – | **바로 직전 행동**이 공격이었고 맞았을 때 / 몬스터가 피했을 때 |
| 아이템 획득 직후 | 소모품 | 바로 직전 행동이 상자를 연 것이고 그 소모품이 나왔을 때 |
| 아이템 사용 직후 | 소모품 | 바로 직전 행동이 그 소모품을 쓴 것일 때 |

- **'직후' 조건은 바로 직전 행동만** 봐요. 그다음 행동(공격·방어·이동·판매 등)을 하면 사라져요. 그래서 방어에 성공한 **그 화면에서** 바로 쓰는 식이에요.
- 조건은 **최대 5개**까지, 같은 종류의 HP 조건은 하나만(이상+이하를 함께 붙여 범위로 쓸 수는 있어요). **'직후' 조건은 하나만** 붙일 수 있어요. 한 번의 행동에서는 한 가지 일만 일어나서 둘을 동시에 만족할 수 없기 때문이에요. 불가능한 조합(범위가 모순이거나 상자에서 얻는 아이템에 몬스터 HP를 붙이는 것 등)은 이유를 알려 주며 거절돼요.
- 싸우는 중에 쓰면 평소처럼 **한 턴을 써요**(몬스터가 공격해요). 방어에 성공해서 몬스터가 기절한 직후라면 몬스터는 이번 공격을 못 해요.

**무기 개조** — `/소모품 추가`·`수정`의 `개조무기`에 무기 이름을 적으면, 그 소모품은 **쓰면 들고 있는 무기가 그 무기로 바뀌어요**(맨손이어도 장착돼요). 회복 효과와는 함께 쓸 수 없고, 예비 칸의 무기는 그대로예요. 이미 그 무기를 들고 있거나 목표 무기가 사라졌으면 쓸 수 없고 소모품도 줄지 않아요. 개조 소모품에도 사용 조건을 붙일 수 있어요(예: 방어 성공 직후에만).

**장비 개조 레시피 (`/장비개조`)** — "특정 재료를 특정 장비(**무기·방패·갑옷 모두**)에 쓰면 개조된 장비로 바뀐다"를 정하는 별도 명령어예요. 위의 `개조무기`(어떤 무기든 정해진 무기로 바꾸는 소모품, 무기 전용)와 달리 **어떤 장비를 들었는지에 따라** 결과가 달라요.
1. `/소모품 추가 이름 이모지 등급 등장 재료:True`로 **개조 재료**를 만들어요. 재료는 효과가 없어요(기존 소모품은 `/소모품 수정 재료:True`로 바꿔요. 새 효과를 정하면 다시 재료가 아니게 돼요).
2. `/장비개조 추가 장비:낡은 스패너 재료:숫돌 결과:레이저 커터`처럼 레시피를 만들어요. **방패도 돼요**: `장비:구리 방열판 재료:숫돌 결과:에너지 실드`. **무기는 무기로, 방패는 방패로, 갑옷은 갑옷으로만** 바뀌어요(종류가 다르면 거절). 갑옷도 돼요: `장비:방진 커버 재료:수선 도구 결과:강철 갑옷`. 같은 재료로 장비마다 다른 결과를 정할 수 있어요(스패너→레이저 커터, 레이저 커터→플라즈마 블레이드, 구리 방열판→에너지 실드 …).
3. 던전에서 **그 장비를 든 채** 아이템 메뉴에서 재료를 쓰면 장비가 결과 장비로 바뀌고 재료는 줄어요. 든 **무기·방패·갑옷 여럿**에 이 재료의 레시피가 있으면 **무기 → 방패 → 갑옷 순**으로 바꿔요(한 번에 한 칸만 바뀌고, 한 번 더 쓰면 다음 칸). 상자에서 재료가 나오게 하려면 소모품의 `등장` 비율을 정해 두세요.
- 든 무기·방패에 맞는 레시피가 없거나 맨손·방패 없음이면 쓸 수 없고, 재료도 줄지 않아요. 어떤 장비에 쓸 수 있는지 알려 줘요. 아이템 메뉴에는 ✨(지금 쓸 수 있음)/🔒가 표시돼요. 예비 칸의 무기는 개조되지 않아요(든 무기만).
- 싸우는 중에 쓰면 한 턴을 써요. 재료에도 `/소모품조건`으로 사용 조건을 붙일 수 있어요.
- 레시피는 `/장비개조 목록`으로 보고 `/장비개조 삭제`로 지워요(최대 50개). 레시피에 쓰이는 장비·결과 장비·재료는 지울 수 없고, 재료를 재료가 아니게 바꿀 수도 없어요. `/던전콘텐츠초기화`로 항목이 사라져 쓸 수 없게 된 레시피는 목록에 ⚠️로 표시돼요.

**지울 수 없는 경우:** 개조 소모품의 목표인 무기, 다른 소모품의 '아이템 획득/사용' 조건이 지켜보는 소모품은 지울 수 없어요(먼저 쓰는 쪽을 바꾸거나 지워 주세요). 시뮬레이션(`/던전시뮬`)의 컴퓨터 플레이어는 조건부·개조 소모품과 개조 재료를 쓰지 않아요(언제 쓸지 계획할 수 없어서).

## 장비 예비 칸
장착한 무기·방패·갑옷과 **별도로 예비 무기 1개, 예비 방패 1개, 예비 갑옷 1개**를 가지고 있다가 서로 **교체**할 수 있어요. **이번 던전 동안만** 쓰고, 던전을 나가거나 다운되면 사라져요(장비·소모품이 던전 안에서만 쓰이는 기존 규칙 그대로예요).

- **예비 칸은 무기 1개·방패 1개·갑옷 1개가 전부예요.** 같은 종류를 둘 넣을 수는 없어요.
- **교체:** 던전 화면의 **[🎒 장비]** 버튼을 누르면 같은 메시지가 장비 화면으로 바뀌어요. **[무기 교체]**·**[방패 교체]**·**[갑옷 교체]**를 누르면 장착한 것과 예비가 서로 바뀌어요. 한쪽이 비어 있으면 버튼이 **[예비에 넣기]**(장착한 것을 예비로, 맨손·맨몸 가드·맨몸이 돼요) 또는 **[꺼내 장착]**(예비를 장착)으로 바뀌어요. 무기·방패·갑옷은 따로 바꿔요.
- **상자에서 새 장비가 나왔을 때**
  - **[장착]**: 새 장비를 쓰고, 지금 장착 중이던 같은 종류의 장비는 **예비 칸이 비어 있으면 거기로 옮겨 가요.** 예비 칸이 차 있으면 기존 장비는 사라지고, 사라졌다고 알려 줘요(예전과 같은 동작이에요).
  - **[예비에 넣기]**: 새 장비를 쓰지 않고 예비 칸에 넣어요. 그 종류의 예비 칸이 **비어 있을 때만** 나타나요. 차 있으면 먼저 장비 화면에서 바꾸거나 팔아요.
- **싸우는 중에는 바꿀 수 없어요**(판매와 같아요). 장비 화면의 버튼은 싸움이 끝난 뒤에 쓰세요.
- 예비 장비도 **던전 안에서 팔 수 있어요**(**[💰 판매]** 화면에 `예비`로 나와요).
- 업데이트 전에 하던 던전은 예비 칸이 비어 있는 상태로 이어져요.

## 던전에서 팔기
던전에서 얻은 **장비와 소모품**은 던전 안에서만 쓰고, 나가거나 다운되면 사라져요. 쓰지 않을 것은 **던전 안에서 팔아서 재화로** 바꿀 수 있어요. 재화는 바로 들어와요.

- **어디서 팔아요?** 던전 화면의 **[💰 판매]** 버튼을 누르면 같은 메시지가 판매 화면으로 바뀌어요. 상자에서 방금 나온 장비는 **[판매 +금액]** 버튼으로 바로 팔 수 있어요(팔면 장착/버리기를 안 정해도 앞으로 갈 수 있어요).
- **무엇을 팔아요?** 새로 나온 장비, 장착 중인 장비, **예비 칸의 장비**, 가지고 있는 소모품. **싸우는 중에는 팔 수 없어요.**
- **한 번에 여러 개:** 판매 화면의 목록에서 여러 개를 골라 **[선택한 것 판매]**. 소모품을 한 개씩만 팔려면 **[1개씩만]**, 소모품을 전부 팔려면 **[소모품 전부]**(고르지 않아도 돼요). 장비는 소모품과 달리 한 개씩 팔려요.
- **얼마에?** 장비·소모품마다 개당 판매가가 있어요. 기본값은 **일반 5 · 희귀 15 · 전설 50**이에요. 0이면 팔 수 없어요.
- **안전장치:** 재화가 최대 보유량을 넘게 되면 **아무것도 팔리지 않아요**(물건을 잃지 않게). 같은 버튼을 연타하거나 지난 화면의 버튼을 눌러도 두 번 받지 않아요.

**판매가 고치기 (관리자)**
| 명령어 | 설명 |
|---|---|
| `/장비 수정 대상 판매가:30` · `/소모품 수정 대상 판매가:0` | 하나만 바꿔요. 0이면 그 물건은 못 팔아요 |
| `/장비 추가 …` · `/소모품 추가 …` 의 `판매가` | 새로 만들 때 정해요. 비우면 등급별 기본값이에요 |
| `/던전판매가 가격:10 대상:소모품 등급:일반` | 한꺼번에 바꿔요. 대상·등급을 비우면 장비와 소모품 전부. `가격:0`이면 전부 못 팔게 돼요 |
| `/던전목록` | 판매가를 같이 보여줘요(못 파는 건 `판매 불가`) |

바꾼 값은 서버마다 따로 저장되고, 진행 중인 던전에도 바로 적용돼요. 등급을 바꿔도 직접 정한 판매가는 그대로 유지돼요. 이 기능이 생기기 전에 직접 편집해 둔 장비·소모품은 등급별 기본 판매가가 적용돼요.

## 던전 밸런스 조정 (관리자)
코드를 열지 않고 디스코드에서 던전 수치를 바꿀 수 있어요. 바꾼 값은 **서버마다 따로** 저장되고, 봇을 껐다 켜도 유지돼요. 진행 중인 던전에도 바로 적용돼요(이미 나타난 몬스터의 체력·공격은 그대로).

| 명령어 | 설명 |
|---|---|
| `/던전설정 항목 값` | 값을 바꿔요. **항목**은 글자를 입력하면 자동완성이 나와요(예: `방어`, `방3`, `보상`). 자동완성에는 지금 값과 기본값이 같이 보여요 |
| `/던전설정확인 [분류]` | 비우면 **바꾼 항목만**, 분류(일반·방 배치)를 고르면 그 분류의 전체 값을 보여줘요. ✏️ = 기본값에서 바꾼 것 |
| `/던전설정초기화 [항목]` | 항목을 고르면 그것만, 비우면 전부 기본값으로 되돌려요(전부일 땐 확인 버튼이 나와요) |
| `/던전시뮬 [판수]` | 지금 밸런스로 컴퓨터가 던전을 대신 돌려 **클리어율**을 보여줘요(방식마다 100~3,000판. 방이 100개라 1,000판에 약 3초, 3,000판에 약 9초 걸려요. 돌리는 동안에도 봇은 평소처럼 응답해요) |

**`/던전설정`으로 바꿀 수 있는 항목** — 이름은 `분류.속성` 모양이에요.
- **일반**: `일반.최대체력` · `일반.맨손공격력` · `일반.층수` · `일반.층당강화` · `일반.층이동회복` · `일반.부활체력` · `방어.성공확률` · `방어.기본피해감소` · `방어.회복률` · `방어.기본반사` · `보상.최소` · `보상.최대` · `보상.획득권확률`
- **방 배치**: `방1.상자` `방1.빈방` `방1.잡몹` `방1.보스` … `방10.보스` — 한 층의 10개 방마다(모든 층에 같게 적용돼요) 네 가지가 나올 **가중치**예요(합이 100일 필요 없이 비율로 써요. 0이면 안 나오고, 한 방의 네 값이 모두 0이면 거절돼요).
- 몬스터·보스·장비·소모품의 수치는 `/몬스터` `/장비` `/소모품` 명령으로 바꿔요(아래).

**안전장치**: 범위를 벗어난 값, 정수여야 하는 곳의 소수, 보상 최소>최대, 한 방/장비/아이템의 가중치가 전부 0인 설정, 나올 몬스터·보스가 하나도 없게 되는 설정은 거절하고 이유를 알려줘요. 거절된 값은 저장되지 않아요. 방어를 반복해서 HP가 줄지 않거나 늘어나는 조합(예: `방어.회복률`을 크게 올림)은 **저장은 되지만 ⚠️ 경고**를 보여줘요. 값을 기본값과 같게 바꾸면 바꾼 기록이 사라져요.

**바꿀 수 없는 것**: 한 층의 방 개수(10개 고정), 보스는 회피 불가라는 규칙, 전투·방어의 진행 방식(가드 성공 시 회복·반사·기절 같은 규칙 자체. 수치는 바꿀 수 있어요).

**시뮬레이션 읽는 법**: 컴퓨터가 장비를 기대 공격력이 높은 쪽으로 고르고 회복 아이템을 알뜰히 쓰면서 세 가지 방식(공격만 / 체력 60% 아래에서만 방어 / 기절 아닐 땐 항상 방어)으로 플레이한 **어림값**이에요. 실제 유저는 보통 이보다 낮게 나와요. 다운되는 방 분포도 같이 나와서, 어디가 벽인지 볼 수 있어요.

## 재화·물품·패키지·던전 편집 (관리자)
모두 **서버마다 따로** 저장되고, 봇을 껐다 켜도 유지돼요. 이모지는 일반 이모지 하나 또는 그 서버의 이모지(`<:이름:ID>`)를 쓸 수 있어요.

**재화** — `/재화설정 [이모지] [이름] [최대]`: 비우면 현재 값을 보여줘요. 이름·이모지는 채팅 반응, 가방, 상점, 안내문, 패키지 결과 등 **모든 화면에 바로 반영**돼요. 최대 보유량을 **낮추면** 그보다 많이 가진 사람이 줄어들기 때문에 몇 명이 줄어드는지 보여주고 확인 버튼을 눌러야 적용돼요(올리는 건 바로).

**물품** — 기본으로 만들어지는 🗝️ 열쇠·🗑️ 쓰레기도 다른 물품과 똑같이 `/물품수정`으로 이름·이모지·설명을 바꾸고 `/물품삭제`로 지울 수 있어요(처음 한 번만 만들고, 지워도 다시 만들지 않아요). 다만 **던전 입장 물품이나 패키지 결과표가 쓰고 있는 물품은 지울 수 없어요**(먼저 `/던전입장물품`·`/패키지결과`에서 바꿔 주세요). `/던전입장물품 물품:입장권 개수:2`처럼 입장에 내는 물품과 개수를 바꾸고, 물품을 비우면 무료 입장이에요. 역할은 입장 물품으로 쓸 수 없어요.

**던전 클리어 보상** — 재화 범위(`보상.최소`·`보상.최대`)와 획득권 확률(`보상.획득권확률`)은 `/던전설정`으로, 추가 물품은 `/던전보상 목록·추가·수정·삭제`(물품·개수·확률 %)로 바꿔요. 물품 보상은 항목마다 **따로 확률을 굴려요**(100이면 항상, 0이면 안 나옴). 클리어했을 때만 나가고 최대 10개예요. 보상으로 쓰는 물품은 지울 수 없어요(먼저 `/던전보상 삭제`).

**패키지 결과** — `/패키지결과 목록`으로 지금 표를 보고, `추가`(종류: 빈 패킷/재화/물품, 확률, 물품, 개수, 이모지, 이름)·`수정`·`삭제`로 바꿔요. **확률은 비율**이라 합이 100이 아니어도 돼요(목록에는 계산된 %가 나와요). 결과가 하나도 없거나 확률이 전부 0이 되는 변경은 거절돼요. 이모지·이름을 비워 두면 물품·재화의 것을 그대로 써요(수정에서 `-`를 적으면 다시 자동으로). 최대 20칸.

**던전 콘텐츠** — `/던전목록`으로 지금 있는 것을 보고 아래 명령으로 바꿔요. 처음 손대는 분류는 지금 목록을 통째로 복사해 와서 그 위에 더하고 빼요(그 분류의 예전 `/던전설정` 숫자는 같이 반영돼요).
- **몬스터·보스가 나올 층 정하기**: `/몬스터 층 대상:오일 슬러지 층:1-3,5`처럼 **여러 층**을 쉼표와 범위(`8-10`)로 정해요(`전체`는 모든 층=기본, 층을 비우면 지금 설정만 보여 줘요). 일반 몬스터도 보스도 같은 명령어예요. 그 층에서 잡몹 방(또는 10번째 보스 방)이 나올 때, **그 층에 나올 수 있는 것들**(층 제한이 없거나 그 층이 들어 있는 것) 중에서 `등장` 비율로 골라요. **층마다 나올 몬스터(보스)가 하나는 남아야 해서**, 어느 층이 비게 되는 설정(`/몬스터 층`이나 `/던전설정 일반.층수` 변경)은 그 층 번호와 함께 거절돼요. 무한모드의 높은 층처럼 정해 둔 제한에 맞는 게 없는 층에서는 제한을 무시하고 모두에서 골라요. `/던전목록`에는 층을 정한 몬스터만 `나오는 층`이 같이 보여요.
- **장비·소모품이 나올 층 정하기**: `/장비 층 대상:레이저 커터 층:1-3,5` · `/소모품 층 대상:소형 배터리 층:전체`처럼 몬스터와 똑같이 **여러 층**을 쉼표와 범위로 정해요(`전체`=모든 층=기본, 층을 비우면 지금 설정만 보여 줘요). **보물 상자**를 열 때만 적용돼요: 그 층에서 나올 수 있는 것(층 제한이 없거나 그 층이 들어 있는 것, `등장` 비율이 0보다 큰 것) 중에서 `등장` 비율로 골라요. 시크릿 보스의 정해진 드롭, `/장비지급`, 장비개조·상점·연금은 층과 상관없어요. **층마다 상자에서 나올 장비와 소모품이 각각 하나는 남아야 해서**, 어느 층이 비는 설정은 그 층 번호와 함께 거절돼요. 무한모드의 높은 층처럼 맞는 게 없는 층에서는 제한을 무시하고 모두에서 골라요. `/던전목록`에는 층을 정한 것만 `나오는 층`이 같이 보여요.
- `/몬스터 추가 이름 이모지 체력 공격 [회피] [보스] [등장]` · `수정` · `삭제` — 보스는 마지막 방에, 잡몹은 짝수 방에 나와요. 보스는 항상 회피 불가예요. `등장`은 같은 종류(잡몹끼리, 보스끼리) 안에서 나올 비율이고 **소수도 돼요**(예: `0.5`, 소수 넷째 자리까지, 0~1000). 안 쓰면 1이라 모두 같은 확률이고, 0이면 안 나와요. `/던전설정`의 `몬스터.○○.등장`·`보스.○○.등장`으로도 바꿔요.
- 방패마다 가드 성공률을 다르게 정할 수 있어요: `/장비 추가`·`/장비 수정`의 **가드성공률**(0~100). 비우면 서버 기본(`/던전설정 방어.성공확률`, 60%)을 쓰고, 수정에서 `-1`은 '해제'(다시 서버 기본)예요. 방패를 끼지 않았을 때와 성공률이 없는 방패는 서버 기본값이에요.
- `/장비 추가 이름 이모지 종류(무기/방패/갑옷) 등급 등장 …` · `수정` · `삭제` — `등장`은 상자에서 나올 비율이고 **소수도 돼요**(예: `0.5`, `0.0125`. 소수 넷째 자리까지, 0~1000). 다른 장비들과의 비율로 계산하니 합이 100일 필요는 없어요. 무기는 공격력·크리티컬·회피변환, 방패는 가드(필수)·반사, 갑옷은 `피해감소`(필수). 수정에서 `-1`은 '해제'예요.
- `/소모품 추가 이름 이모지 등급 등장 …` · `수정` · `삭제` — `등장`은 장비와 같이 소수가 돼요. 회복은 한 가지: 회복량 / 전체회복 / 지속회복(+지속턴), 또는 **무기 개조**(`개조무기`). 여기에 아래 **소모품 새 효과**를 함께 붙일 수 있어요(개조 소모품·재료는 다른 효과 없음). 수정에서 새 회복 효과를 정하면 이전 회복 효과는 사라져요. 사용 조건은 아래 `/소모품조건`.
- `/소모품조건 추가 소모품 조건 [값] [아이템]` · `삭제 소모품 번호` · `비우기 소모품` · `목록 [소모품]` — 소모품에 **사용 조건**을 붙여요(자세한 내용은 위의 **조건부 소모품과 무기 개조**).
- `/던전콘텐츠초기화 [분류]` — 직접 만든 것·바꾼 것을 기본 목록으로 되돌려요(확인 버튼).
- 이름은 같은 분류 안에서 겹칠 수 없어요(몬스터와 보스는 서로의 이름도 쓸 수 없어요). 분류당 몬스터·보스 25개, 장비·소모품 50개까지.
- **진행 중인 던전은 깨지지 않아요**: 지운 장비를 쓰고 있던 사람은 맨손처럼 싸우고, 아직 정하지 않은 상자 장비가 지워졌다면 [장착]/[버리기]를 눌러 안내만 받고 앞으로 갈 수 있고, 지운 소모품은 소지품에서 안 보여요. 이미 나온 몬스터는 그대로 싸워요.

## 역할 재화 지급 (관리자)
`/역할재화지급 역할:@손님 수량:30`처럼 쓰면 그 역할을 가진 **모든 사람**에게 💾를 줘요(수량이 음수면 회수).
- **확인 단계**: 명령을 치면 대상 인원과 총량을 먼저 보여주고, **[지급] 버튼을 눌러야** 실제로 나가요(취소하면 아무것도 안 바뀌어요). 미리보기에 나온 명단 그대로 처리돼요.
- **대상**: 그 역할을 가진 사람 중 **봇은 제외**해요. `@everyone`을 고르면 서버의 모든 사람이에요.
- **한도**: 사람마다 0~최대 보유량(기본 9,999,999,999개) 안으로 맞춰요. 상한 때문에 덜 받거나 0 아래로 못 내려간 사람이 몇 명인지 결과에 알려줘요. 전부 한 번에 저장돼서 수천 명도 빠르고, 중간에 실패하면 아무에게도 반영되지 않아요.
- **기록**: 누가·어느 역할에·몇 명에게·얼마를 줬는지 봇 콘솔 로그에 남아요.

**켜는 방법 (처음 한 번)** — 이 기능은 역할을 가진 사람 전체를 알아야 해서 *서버 멤버 인텐트*가 필요해요. 안 켜면 다른 기능은 그대로 되고, 이 명령만 켜는 방법을 안내하고 멈춰요.
1. 개발자 포털 → 봇 → **Bot** 탭 → **Server Members Intent**를 켜요.
2. `.env`에 `MEMBERS_INTENT=true`를 적어요.
3. 봇을 다시 시작해요.

포털에서 인텐트를 안 켜고 `.env`만 `true`로 하면 봇이 시작되지 않고 그 이유를 알려줘요(`.env`의 값을 지우면 돌아와요). 인텐트를 켜도 시작할 때 모든 멤버를 미리 불러오지는 않아요.

## 처음 설정 순서 (관리자)

6. (선택) 재화 이름·이모지는 `/재화설정`, 던전 입장 물품은 `/던전입장물품`, 패키지에서 나오는 것은 `/패키지결과`, 던전의 몬스터·장비는 `/몬스터` `/장비` `/소모품`.

## 자세한 규칙
**재화와 쿨타임.** 같은 사람이 **3초 안에 연달아 보낸 메시지는 한 번으로** 셉니다(매크로·도배로 재화를 긁는 것을 막으려는 안전장치예요). 확률·쿨타임은 `/이벤트설정`으로 바꾸고, `재화쿨타임:0`이면 모든 메시지를 세요. 패키지 확률도 같은 방식으로 센 메시지에만 적용돼요. 재화를 얻으면 메시지에 재화 이모지(기본 💾) 반응이 붙어요(바쁜 채널에서는 요청 제한을 피하려고 채널마다 1초에 한 번만).

**최대 보유량.** 재화는 기본 9,999,999,999개가 최대예요(`/재화설정`으로 변경, 설정할 수 있는 최대도 9,999,999,999개). 예전에 기본값(99,999) 그대로 쓰던 서버는 처음 시작할 때 이 값으로 한 번 올라가요(직접 정해 둔 최대는 그대로, 가진 재화도 그대로). 채팅·패키지 보상은 상한까지만 들어가고, 판매는 **상한을 넘기게 되면 거절**해요(물건을 잃지 않게). 물품 가격도 이 최대값까지만 정할 수 있어요.

**패키지.** 나타난 채널에서 **120초** 동안 머물러요(`/이벤트설정`으로 변경). 한 채널에는 한 번에 하나만 나와요. 두 가지 방식이 있어요.
- **누구나 한 번씩**(기본): 패키지를 낸 사람이 아니어도 모두 뜯을 수 있고, **각자 자기 결과**를 받아요(본인에게만 보임). 끝나면 몇 명이 무엇을 얻었는지 요약돼요.
- **먼저 뜯은 한 명만**: 가장 먼저 뜯은 사람이 가져가고, 결과가 모두에게 공개돼요.
**패키지 더미.** 패키지가 나타나는 순간 **35% 확률로 더미로 변이**해서 나와요. 더미는 📦📦📦 모양에 금색 안내(`📦📦📦 패키지 더미가 나타났어요!`)로 일반 패키지와 구분돼요.
- **뜯으면 결과가 3개** 나와요. 결과표(`/패키지결과`)에서 **3번을 따로 뽑아서**, 같은 결과가 여러 번 나올 수도 있고 **빈 패킷·재화·물품이 섞일 수 있어요**(결과표의 확률이 그대로 쓰여요). 3개 모두 바로 가방과 지갑에 들어가고, 재화가 최대 보유량을 넘으면 넘는 만큼은 못 받는다고 알려 줘요.
- 뜯는 규칙은 일반 패키지와 같아요: 사람마다 한 번, 선착순 방식이면 첫 사람이 3개를 모두 가져가요. 뜯으면 **패키지 쿨타임도 똑같이** 시작돼요. 끝나면 요약에 3개씩 합쳐서 보여 줘요.
- 더미 여부는 **나타날 때 정해져서** DB에 저장돼요. 봇을 껐다 켜도 그대로 더미예요. 업데이트 전부터 나와 있던 패키지는 일반으로 이어져요.
- **관리자:** `/이벤트설정 더미확률:50 더미개수:5`처럼 바꿀 수 있어요(확률 0~100%, 개수 1~10). `더미확률:0`이면 더미가 안 나와요. 설정 화면과 `/도움말`에도 보여요.

**패키지 쿨타임.** 패키지를 뜯으면(결과가 빈 패킷이어도) **30초** 동안은 다른 패키지를 뜯을 수 없어요. 그 사이에 누르면 "N초 뒤에 다시 뜯을 수 있어요"라고 알려 주고, 아무것도 받지 않고 주사위도 굴리지 않아요. 선착순 패키지라면 기다려야 하는 사람 때문에 패키지가 닫히지 않아요. 같은 패키지를 또 누르면 쿨타임과 상관없이 "이미 뜯었어요"가 나와요. 사람마다 서버마다 따로 세고, 봇을 껐다 켜도 이어져요. `/이벤트설정 패키지쿨타임:60`처럼 바꾸고 `0`이면 제한이 없어요.
봇을 껐다 켜도 이미 나온 패키지와 상점 버튼은 그대로 동작해요.

**상점.** 구입·판매가 모두 꺼진 물품은 상점에 안 나오고 가방에만 있어요. 상점에는 **최대 25개**(디스코드 선택창 한도)까지 올릴 수 있어요. 구입을 켜면 구입가가 1 이상, 판매를 켜면 판매가가 0이 아니어야 해요(음수·범위도 돼요). 같은 사람이 버튼을 연타해도 이중으로 결제되지 않아요.

**역할 상점.** 안전을 위해 **관리자·서버 관리·역할 관리·채널 관리·멘션 전체·추방·차단 같은 관리 권한이 있는 역할은 올릴 수 없어요.** 봇의 역할보다 위에 있는 역할, 봇·연동이 관리하는 역할, `@everyone`도 안 돼요. 역할을 주는 데 실패하면 **낸 재화를 바로 돌려드려요**. 역할을 판매할 때는 역할을 거둔 뒤에 재화를 줘요.

**물품 삭제.** 되돌릴 수 없어서 확인 버튼이 나오고, 사람들의 가방에 있던 물품도 함께 사라져요. 던전 입장 물품이나 패키지 결과표가 쓰는 물품은 지울 수 없어요.

## 실행
1. Python 3.10 이상을 설치하고, 개발자 포털에서 봇을 만들어 토큰을 복사해요.
2. **Windows**: `start.bat`을 두 번 클릭하면 끝까지 알아서 해요.
   - 파이썬(`py`, `python`, `python3` 순서로 찾아요)이 없거나 **3.10보다 낮으면** 설치 주소를 알려 주고 멈춰요.
   - `.env`가 없으면 만들고, **봇 토큰이 비어 있으면 메모장을 열어요.** `DISCORD_TOKEN=` 뒤에 토큰을, `GUILD_ID=` 뒤에 서버 ID를 적고 **저장한 뒤 메모장을 닫으면** 같은 창에서 이어서 진행돼요(다시 실행할 필요 없어요).
   - 가상환경(`.venv`)을 만들고(망가져 있으면 새로 만들어요), `requirements.txt`가 바뀌었거나 패키지가 빠졌을 때만 설치한 뒤 `main.py`를 실행해요.
   - 오류로 끝나면 창이 바로 닫히지 않고 **종료 코드와 원인을 볼 수 있게 멈춰요.**
   - `start.bat`은 **Windows 줄바꿈(CRLF)** 파일이에요. 편집기에서 줄바꿈을 바꿔 저장하면 오동작할 수 있어요(`.gitattributes`가 깃에서 바뀌지 않게 지켜요).
3. **터미널**: `pip install -r requirements.txt` → `.env.example`을 `.env`로 복사해서 채우기 → `python main.py`.
4. 콘솔에 `서버 ID …: 슬래시 명령어 36개 등록 완료`가 뜨면 성공이에요. `GUILD_ID`를 비우면 모든 서버에 등록되는데 반영까지 최대 1시간 걸려요.

**옛 명령어는 시작할 때 자동으로 지워요.** 예전에 `GUILD_ID` 없이 켰다가 지금은 `GUILD_ID`를 쓰거나(또는 반대로) 바꾸면, 코드에 없는 옛 명령어가 디스코드에 남아서 눌러도 응답하지 않아요. 봇이 켜질 때 쓰지 않는 쪽에 남은 명령어를 찾아 지우고 콘솔에 `옛 명령어 N개를 지웠어요: /…`로 알려 줘요. 지금 쓰는 명령어는 건드리지 않아요.

**토큰은 채팅·스크린샷·깃허브에 절대 올리지 마세요.** `.env`와 `data/`는 `.gitignore`에 들어 있어요.

## 알아둘 점
- **경험치(EXP) 기능은 없어졌어요.** 예전 버전에서 쌓인 EXP 숫자는 데이터베이스에 그대로 남아 있지만 어디에도 쓰이지 않아요(지우지 않았어요). 예전 `/이벤트설정`의 경험치 값도 무시돼요.
- 물품 목록은 **서버당 하나**예요. 여러 채널에 상점을 띄우면 모두 같은 목록이 보여요(채널마다 다른 상점은 지원하지 않아요).
- 이모지는 일반 이모지 하나 또는 그 서버의 이모지(`<:이름:ID>`)만 쓸 수 있어요. 서버 이모지는 본문에서는 그림으로 보이지만 선택창 설명에서는 그림으로 안 보여서, 거기서는 재화 이름으로 대신 보여줘요.
- 이름 뒤의 조사(이/가, 은/는)는 받침을 보고 자동으로 붙여요. 영문·숫자로 끝나는 이름은 어색할 수 있어요.
- 봇이 꺼져 있는 동안의 채팅에는 보상이 없어요.
