# 🎃 할로윈 봇

이벤트 채널에서 채팅하면 **🍬 할로윈 재화**를 모으고, 가끔 나타나는 **📦 패키지**를 뜯고, **상점**에서 물품과 역할을 사고파는 디스코드 봇이에요.

## 규칙 한눈에
| 항목 | 내용 |
|---|---|
| 재화 | 이름은 **할로윈 재화**, 아이콘은 🍬. 최대 **99,999개** |
| 채팅 보상 | 채팅 한 번에 **50%** 확률로 🍬 **1~5**개 |
| 경험치 | 채팅하면 EXP도 쌓여요(기본 15~25, 60초에 한 번). **EXP 15,000 → 🍬 15** 교환(`/경험치교환`) |
| 패키지 | 채팅 한 번에 **0.1%** 확률로 그 채널에 나타남. 뜯을지 말지는 각자 선택 |
| 패키지 결과 | **꽝 60%** · 🗝️ 열쇠 20% · 🍬 50개 10% · 🗑️ 쓰레기 10% |
| 상점 | 관리자가 물품·역할을 등록. 물품마다 **구입 true/false**, **판매 true/false** |
| 가방 | `/가방`: 내 재화·경험치·물품·가진 역할 |
| 채널 지정 | 재화·EXP·패키지는 **관리자가 정한 이벤트 채널에서만** |

## 명령어
**누구나**
| 명령어 | 설명 |
|---|---|
| `/가방` | 내 재화·경험치·물품 확인 (본인에게만 보임). 여기서 EXP 교환도 할 수 있어요 |
| `/경험치교환 횟수:1` | EXP 15,000을 내고 🍬 15를 사요 (한 번에 여러 번 가능) |
| `/도움말` | 이 서버의 확률·채널이 반영된 안내 |
| `/던전` | 🗝️ 열쇠 1개로 던전에 들어가요. 진행 중이면 열쇠 없이 이어서 해요 (본인에게만 보임) |

**관리자 전용** (서버 관리자 또는 서버 주인. 일반 멤버에게는 메뉴에도 안 보여요)
| 명령어 | 설명 |
|---|---|
| `/이벤트채널추가` `/이벤트채널제거` `/이벤트채널목록` | 재화·EXP·패키지가 나오는 채널 지정 |
| `/이벤트설정` | 확률·쿨타임·패키지 방식 변경. 비워 두면 현재 설정 |
| `/상점등록 채널:` | 그 채널에 상점을 띄워요 (비우면 지금 채널). 같은 서버에서 여러 채널에 띄울 수 있어요 |
| `/상점해제` | 그 채널의 상점 메시지를 없애요 (물품·가방은 그대로) |
| `/물품등록 이름 구입 판매 [구입가] [판매가] [설명] [이모지]` | 물품 등록 |
| `/역할등록 역할 구입 판매 [구입가] [판매가] [설명] [이모지]` | 역할 등록. 사면 그 역할을 받아요 |
| `/물품수정` `/물품삭제` `/물품목록` | 가격·구입·판매 수정 / 삭제(확인 버튼) / 전체 목록 |
| `/재화지급` `/경험치지급` `/물품지급` | 지급하거나 회수(−). 이벤트 보상·실수 복구용 |

## 던전
패키지에서 얻은 🗝️ 열쇠 1개로 `/던전`에 들어가요. 방이 **10번** 나오고(몬스터 30% · 빈 방 30% · 보물 상자 20% · 미니 보스 20%), 턴제로 싸워요. HP는 1,000이에요.
- **전투**: 공격(기본 80% 명중) · 방어(가드 성공 60%, 성공하면 피해 감소) · 아이템 사용(전투 중엔 한 턴을 써요).
- **상자**: 장비 1개 + 소모품 1개. 장비는 **장착/버리기**를 정해야 앞으로 갈 수 있어요. 장비·소모품은 그 던전 안에서만 써요.
- **끝**: 10번째 방을 마치면 클리어(🍬 50~150 + 10% 확률로 🎟️ 히든 칭호 획득권). 쓰러지거나 나가면 보상 없이 끝나고 열쇠는 돌아오지 않아요.
- **이어하기**: 봇이 꺼지거나 화면을 닫아도 진행은 저장돼요. `/던전`을 다시 치면 열쇠 없이 이어서 해요. 클리어 보상은 한 번만 나가요.
- 획득권은 `/가방`에 표시돼요. (칭호 교환 기능은 아직 없어요.) 확률·보상 값은 `dungeon.py` 맨 위 상수에서 바꿔요.

## 처음 설정 순서 (관리자)
1. `/이벤트채널추가 채널:#할로윈` — 재화와 패키지가 나올 채널을 정해요.
2. `/물품등록 이름:호박 초 구입:true 판매:true 구입가:30 판매가:10 이모지:🕯️` — 물품을 등록해요.
3. `/역할등록 역할:@유령 손님 구입:true 판매:false 구입가:200` — 사면 역할을 받는 물품이에요.
4. `/상점등록 채널:#상점` — 그 채널에 상점이 떠요. 물품을 바꾸면 상점 메시지가 **자동으로 새 목록**으로 바뀌어요.
5. (선택) 🗝️ 열쇠와 🗑️ 쓰레기는 처음엔 가방에만 쌓여요. 사고팔게 하려면 `/물품수정 물품:쓰레기 판매:true 판매가:2`.

## 자세한 규칙
**재화와 쿨타임.** 같은 사람이 **3초 안에 연달아 보낸 메시지는 한 번으로** 셉니다(매크로·도배로 재화를 긁는 것을 막으려는 안전장치예요). 확률·쿨타임은 `/이벤트설정`으로 바꾸고, `재화쿨타임:0`이면 모든 메시지를 세요. 패키지 확률도 같은 방식으로 센 메시지에만 적용돼요. 재화를 얻으면 메시지에 🍬 반응이 붙어요(바쁜 채널에서는 요청 제한을 피하려고 채널마다 1초에 한 번만).

**최대 보유량.** 재화는 99,999개가 최대예요. 채팅·패키지 보상은 상한까지만 들어가고, EXP 교환과 판매는 **상한을 넘기게 되면 거절**해요(물건이나 EXP를 잃지 않게).

**패키지.** 나타난 채널에서 **120초** 동안 머물러요(`/이벤트설정`으로 변경). 한 채널에는 한 번에 하나만 나와요. 두 가지 방식이 있어요.
- **누구나 한 번씩**(기본): 패키지를 낸 사람이 아니어도 모두 뜯을 수 있고, **각자 자기 결과**를 받아요(본인에게만 보임). 끝나면 몇 명이 무엇을 얻었는지 요약돼요.
- **먼저 뜯은 한 명만**: 가장 먼저 뜯은 사람이 가져가고, 결과가 모두에게 공개돼요.
봇을 껐다 켜도 이미 나온 패키지와 상점 버튼은 그대로 동작해요.

**상점.** 구입·판매가 모두 꺼진 물품은 상점에 안 나오고 가방에만 있어요. 상점에는 **최대 25개**(디스코드 선택창 한도)까지 올릴 수 있어요. 구입을 켜면 구입가, 판매를 켜면 판매가가 1 이상이어야 해요. 같은 사람이 버튼을 연타해도 이중으로 결제되지 않아요.

**역할 상점.** 안전을 위해 **관리자·서버 관리·역할 관리·채널 관리·멘션 전체·추방·차단 같은 관리 권한이 있는 역할은 올릴 수 없어요.** 봇의 역할보다 위에 있는 역할, 봇·연동이 관리하는 역할, `@everyone`도 안 돼요. 역할을 주는 데 실패하면 **낸 재화를 바로 돌려드려요**. 역할을 판매할 때는 역할을 거둔 뒤에 재화를 줘요.

**물품 삭제.** 되돌릴 수 없어서 확인 버튼이 나오고, 사람들의 가방에 있던 물품도 함께 사라져요. 열쇠·쓰레기(기본 물품)는 지울 수 없어요.

## 봇 초대와 권한
- 초대할 때 **`bot`**, **`applications.commands`**를 선택하세요.
- 필요한 권한: **채널 보기, 메시지 보내기, 링크 첨부(임베드), 반응 추가**(선택), 그리고 **역할 관리**(역할 상점을 쓸 때만). 역할 상점을 쓴다면 서버 설정에서 **봇 역할을 판매할 역할들보다 위로** 옮겨 주세요.
- **특권 인텐트(메시지 내용·서버 멤버)는 켤 필요가 없어요.**

## 실행
1. Python 3.10 이상을 설치하고, 개발자 포털에서 봇을 만들어 토큰을 복사해요.
2. **Windows**: `start.bat`을 두 번 클릭 → 처음엔 `.env`가 열려요 → `DISCORD_TOKEN`(과 `GUILD_ID`)을 적고 저장한 뒤 다시 실행.
3. **터미널**: `pip install -r requirements.txt` → `.env.example`을 `.env`로 복사해서 채우기 → `python main.py`.
4. 콘솔에 `서버 ID …: 슬래시 명령어 18개 등록 완료`가 뜨면 성공이에요. `GUILD_ID`를 비우면 모든 서버에 등록되는데 반영까지 최대 1시간 걸려요.

**토큰은 채팅·스크린샷·깃허브에 절대 올리지 마세요.** `.env`와 `data/`는 `.gitignore`에 들어 있어요.

## 데이터
재화·가방·상점 정보는 `data/halloween.sqlite3` 한 파일에 저장돼요. **이 파일을 복사해 두면 백업**이에요(봇을 끈 상태에서). 호스팅을 쓴다면 `data` 폴더가 재시작·재배포 때 유지되는지 꼭 확인하세요. 지워지면 모두의 재화와 가방이 사라져요.

## 알아둘 점
- **EXP는 이 봇이 직접 쌓는 것**이에요. MEE6 같은 다른 레벨링 봇의 EXP는 읽을 수 없어요. 그 EXP를 쓰고 싶다면 `/경험치지급`으로 옮기거나, 연동 방식을 따로 정해야 해요.
- 물품 목록은 **서버당 하나**예요. 여러 채널에 상점을 띄우면 모두 같은 목록이 보여요(채널마다 다른 상점은 지원하지 않아요).
- 이모지는 일반 이모지 하나 또는 그 서버의 이모지(`<:이름:ID>`)만 쓸 수 있어요.
- 봇이 꺼져 있는 동안의 채팅에는 보상이 없어요.

## 검증
자동 시험 **177개**가 통과합니다. 확률은 경계값(정확히 50%, 0.1%, 60/80/90%)과 대량 표본(채팅 2만 번, 패키지 결과 40만 번)으로 확인했고, 재화 상한·교환·판매·역할 환불·연타·관리자 전용·패키지(누구나/선착순)·재시작 후 버튼 등록을 시험해요. 일부러 코드를 망가뜨린 **35가지를 모두 시험이 잡아냈어요.** 한글 옵션 이름이 실제 명령 처리 경로에 제대로 연결되는지, 봇을 켤 때의 시작 순서(확장 불러오기·고정 버튼 등록·서버별 명령어 등록)도 확인했어요.

**직접 확인하지 못한 것**: 실제 디스코드 접속, 화면이 실제로 어떻게 보이는지(임베드·선택창·버튼 배치), 서버 이모지가 선택창에서 보이는지, 봇 권한과 역할 순서에 따른 역할 지급 성공 여부, 재시작 뒤 이미 올라간 버튼이 실제로 응답하는지. **테스트 서버에서 먼저** 위 순서대로 확인해 보세요.
